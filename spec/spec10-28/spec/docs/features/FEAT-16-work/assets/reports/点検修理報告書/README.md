## 2. 正式输出与原件差异

- 正式输出为A4纵向PDF；全部内容完整显示，允许区域增高、自然续页，不以原件四个実施内容槽位、每组五行处置或单页容量截断。
- 原件没有保存明确纸张、方向、打印区域、缩放及分页方案；不能把软件默认打印结果当作正式版式。原件使用范围B1:Q44，报告主体主要为B:J；K列是填写提醒，不纳入正文；格式延伸到Q列不代表应当输出。正式报告不含照片。
- 标题及固定栏目文字沿原件；「作業完了日」标签保留但按生成当天默认，可修改；本次受付登记4年目时，下次安排为生命周期基准月＋5年的报废予定，标签相应显示为「廃棄予定」，不固定印「次回定期点検日」。
- 原字体以ＭＳ明朝为主，含游ゴシック；行高、列宽、合并和样例位置仅作为原版式证据，不限制长内容。具体字体与分页实现沿后续PDF方案和样稿核对，不据此新增PDF框架。
- 原件中的客户、编号、日期序号、○、处置、`0`、`同左`及`85cm`等均为样例，不作为默认业务值。固定版式号`PAF-2401.1`删除，系统报告生成版本及历史照常保留。
- K7／K11／K12／K31旁注不进入正式报告，也不放生成界面；“展开维修必须填写经过”等提示不作为校验依据。**任何内容字段是否填齐均不影响报告生成。**

## 3. 被替代的原字段说明与讨论规则

| 原说明／历史讨论 | 当前有效规则 |
|---|---|
| 字段表C8／C9按识别订单读取客户、納品先；曾讨论报告納品先回退订单 | 只取大番号已保存客户／納品先，报告内可补充修改；納品先缺失不回退订单。FEAT-14左侧参考回退规则保持原样 |
| C10「读取订单中请求书」未明确订单；C12「该订单下首次出货」 | 只取本产品当前关联订单的已保存請求先名称及本产品在该订单第一次实际寄出日期；无当前关系／出货事实则空，不自动取历史订单 |
| 上方部件读取当前产品编号；C27泛称「产品版本号」 | 上方取小番号成立时保存的起始部件编号与传感器固件版本；后续不覆盖；缺失可仅在本报告补录 |
| C38:C40「换了编号或者版本号也补录」；曾讨论列出每次更换过程 | 比较报告采用的起始值（含本次补录）与本次作业生成时最新保存值，相同不重复显示，不同只显示最新值；不列中间过程，不另外核实线下实物 |
| 实施内容样例含修理、清洗；原件只有四格 | 仅本次受付N年目及全部受付NG文字，只读、无照片、完整显示 |
| C43／C44按当前时间小于／大于第四年判断下次 | 按生命周期基准月及本次登记年目：1～3年目对应下一年目点检，4年目对应基准月＋5年的报废予定；缺依据留空，报告内可补充修改 |
| C46展开维修／清洗取受付要求 | 默认分别取本小番号展开维修目录登记／清洗完成记录；允许报告内修改，不回写作业 |
| C46维护由维修受付类型自动勾选 | 维护与其他均在生成报告时人工勾选，只进入本次报告 |
| K31勾选展开维修后必填经过；曾讨论保留必填校验 | 展开经过始终选填；所有内容缺项均不阻断生成；旁注不在正式报告或生成界面显示 |
| C45报告生成日期与「作業完了日」标签语义冲突 | 用户确认保留标签，默认生成当天，可报告内修改，不作为实际作业完成事实 |
| C49公式`=--G13`及I44版式号 | 公式不执行、不作为规则；I44版式号不输出，不影响系统版本和内部模板采用依据 |
| 既有“PDF内容与格式待正式需求”条款、旧原型字段 | 对单台点检报告由本次正文、字段对照和说明替代；原记录与截图保留为历史证据，不证明新需求已经实现 |
| 重复生成时可能沿用上一版人工值 | 每次重新按来源规则带出，不自动继承上一份报告人工内容 |

来源优先级：当前有效正文及字段对照 → 本采用说明 → 附件中未被替代的版式／栏目证据。原始样例和旧讨论不能覆盖最新裁决。其他报告、返送納品書、面单及模板在线替换不在本次需求确认范围内。
