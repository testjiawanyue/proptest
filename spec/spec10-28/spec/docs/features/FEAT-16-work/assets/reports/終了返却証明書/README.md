## 2. 被替代内容及正式版式

| 原件／此前讨论 | 当前有效规则 |
|---|---|
| Sheet名「廃棄案内状」 | 按标题与正文识别为本回收报告；不作为报废报告材料 |
| 左栏「管理番号」、右栏「製造番号」 | 两栏统一「製造番号」，取所选当前PROP回收计划产品，自动带出且只读 |
| 原件没有受付番号；旧§5.9及分析曾要求PDF增加第二行 | 回收PDF不显示受付番号，候选列表仍显示製造番号＋受付番号用于识别；不改变所选受付身份 |
| No.与日期等样例 | No.取大番号只读；发行日默认生成当天、可报告内修改或清空，有值时按日文年月日，清空后留空、不补当天；每台返却日默认大番号受付日，可逐台修改或留空，不回写受付 |
| 客户、支店、PROP样例 | 客户／納品先只取大番号已保存值，可仅本次补充修改；PROP读取业务字典，只读且不放生成界面，生成冻结，不抄样例 |
| 此前发行日清空及内容缺项仍待裁决 | 沿用单台点检报告规则：发行日可清空，抬头、PROP等内容缺失或未填写不阻断生成，缺失处留空，不自动补其他来源；空值冻结，来源随后补齐不改旧版。字段编辑范围、至少选择一台及整组复核不变，真实技术失败不视为内容缺项 |
| 标题、御中、ご返却明細、证明正文及底部三条说明 | 保留原文，生成时不可编辑，不触发收费／账单／实际回收，也不增加实际回收等生成门槛 |
| 固定10行×左右两栏 | 不构成20台上限；按小番号升序，先左栏自上而下再右栏，满页续页；少量保留基本高度及空白行，长编号可增高，不缩字硬塞 |
| 原件未声明纸张／打印区／分页方案 | 正式采用A4纵向、Noto日文字体；主标题18pt，客户／御中／明细及表格主要内容14pt并按原件加粗，製造番号与返却日的值统一14pt（2026-10-17最新裁决，替代返却日12pt），正文／PROP／底部说明11pt |
| 原字体HG丸ｺﾞｼｯｸM-PRO及宋体，原日期为Excel数值 | 字体以确认的Noto为准；日期按业务含义采用，不直接打印序列值，不把预览器本地化日期样式当正式规则 |
| 曾建议说明只在最后一页 | 未采用。三条说明在表格后保持完整段落自然接续，不强制仅末页；PROP不逐页重复 |
| 引用报废通知的双栏实现 | 仅沿用续页呈现：标题／大番号／发行日、跨页表头、居中页码；不移植其左右逐行排序、业务字段或处理资格 |

正文与字段对照优先于本说明；本说明及附件中未被替代的区域关系共同指导后续样稿。原件没有明确纸张、方向、打印区域、缩放或手动分页，不把软件默认打印结果当已确认方案。原件行高、列宽、合并及留白仅为基底，具体尺寸随后续样稿目视核对。

## 3. 生效范围与历史

本次条款替代回收报告“全部PDF字段仍待确认”的笼统状态、旧PDF必须带受付番号及未采用的续页建议；历史讨论／材料／评审报告保留，不追溯改写为新规则已实现。大番号头部入口、当前计划候选、整组复核、独立版本、冻结历史、删除保护及实际处理边界继续沿正式§5.9。

单台点检报告及其作业／返送双入口不变。报废报告模板待提供，继续延期；本原件及本需求均不替代报废模板，不自动授权实施、部署或其他D切片。

2026-10-17版式补充裁决：左右同行同步增高、横线及表底对齐；製造番号和返却日的值同为14pt。原Excel只读保留，原件字号差异不覆盖本次裁决。
