# 单台点检报告字段对照（2026-10-16采用版）

本表是[FEAT-16 §5.8](spec.md#58-单台点检报告内容与输出2026-10-16裁决)的正式字段明细，适用于作业管理及返送详情的同一份单台点检报告；不是现有接口／实现完成声明。原Excel单元格仅用于定位，PDF允许区域增高、自然续页，不固定格数或行数。附件及旧说明替代关系见[模板README](assets/reports/点検修理報告書/README.md)。

## 1. 共同规则与冻结时点

- **成立时起始记录**：本次小番号成功成立时保存当时部件编号和传感器固件版本；后续更换、补录、升级均不覆盖。原始缺项保留空白，不取历史绑定补齐。
- **本次报告快照**：正式生成时保存本次报告实际采用的完整内容，包括文字、编号、日期、勾选及人工补充／修改后采用的内容。下表“冻结内容”表示需保留的报告内容，不预设存储结构，不强制另存多份来源原值、完整比较数据、计算依据或模板标识；具体保存方式由后续实施方案确定。不在预览／下载／打印时重新读取最新业务资料或字典。
- **报告内编辑**：仅下表允许的项可在本次报告修改；不回写大番号、产品、订单、寄送、受付、作业、起始记录或业务字典。只读项需先改对应源资料，再生成新报告。
- **空值**：任何内容字段缺失都不阻止生成；无值留空，不补样例、零、历史订单／绑定、检查○或未经指定的当天。展开经过始终选填。所属小番号、真实版本、生成时间和发行人仍由系统维护，不属于人工内容必填校验。
- **再次生成**：重新按每个字段的来源规则带出；不继承上一份报告的人工填写、补录、覆盖和勾选。

**编号／固件版本比较规则**：

1. 报告上方显示起始记录；没有起始记录的旧小番号也默认留空，不以当前值自动倒填。缺失起始值可在报告中补录，不改源记录。
2. 另一端取本小番号作业截至生成时**最新保存结果**，包括未处理时仍维持的状态；不设「最终版本」、不要求完成，不混用其他小番号后续作业结果。对应绑定缺失／已解绑时留空，不取历史绑定。
3. 比较的是报告内实际采用的起始值（含本次补录）与最新保存值：相同则处置中不重复显示编号／版本，不同则显示对应最新值；最新值为空时仍留空，不拿旧值补位。
4. 「更换」文字由作业处置选项体现，系统不据编号差异另外推导线下事实。中间保存或误录后修正过程不进入报告。

示例：起始`HK-221025`，中间误录`HK-251300`后修正为`HK-251305`，报告上方为`HK-221025`，处置中仅追加`HK-251305`。起始缺失、报告补录`HK-221025`且最新也为`HK-221025`时，不追加编号。固件版本按同一规则处理。

## 5. 系统版本与内容一致性

每次成功生成对应小番号的一个新不可变版本，记录真实生成时间、发行人，保存本次报告实际采用的完整内容，保证历史报告不变。系统版本不是原模板版式号，修改「作業完了日」不改变真实生成时间或历史排序。两个入口以及预览／下载／打印使用同一版本内容。文件生成或保存失败不伪造成功／版本；字段内容缺项与技术生成失败分别处理。验证场景见[VAL-IR系列](validation.md#val-ir-01-抬头来源与报告内修改2026-10-16待实施)。
