# 大番号回收报告字段对照（2026-10-17确认版）

本表是[FEAT-16 §5.9／§5.9.1](spec.md#591-回收报告字段增量2026-10-17逐项确认)的正式字段明细，与[模板采用说明](assets/reports/終了返却証明書/README.md)及[VAL-RR验证清单](validation.md#val-rr-01-抬头与身份待实施)配套。仅整理已确认需求，不表示实现、PDF样稿、运行或设备验收已通过。原件单元格用于定位，不限制动态内容长度或产品数量。

## 1. 来源、报告内编辑与冻结

- 自动带出值按下表来源读取；仅允许编辑的字段可在本次报告补充或修改。修改仅保存本次采用内容，不回写大番号、受付、产品、订单、作业或字典。
- 正式成功生成时保留本次实际采用的完整文字、日期、顺序及勾选产品清单，记录真实生成时间和发行人。之后业务资料、产品计划、字典或合法删除变化不改写历史。预览、下载及打印使用同一正式版本内容，不重新带入当前业务值。
- 已确认可空的返却日可逐台留空；客户／納品先无保存值时带出为空，可在本次报告补充。不填样例，不回退订单，不将发行日、实际回收确认时间替代返却日默认来源。
- **内容缺项不阻断生成（2026-10-17补充裁决）**：沿用单台点检报告规则，发行日允许清空，抬头、PROP等内容缺失或未填写均留空，不自动补取其他来源、样例或历史值；清空发行日后不重新补当天。空值一并冻结，来源随后补齐不改写历史。此规则不扩大字段编辑范围，PROP仍只读，也不取消候选复核等业务条件；真实读取、生成或保存失败不冒充内容缺项。
- 至少选择一台；确认时重新复核所有所选受付仍有效、属于本大番号且当前计划为PROP回收。失效说明对应产品及原因，要求重新确认，不静默剔除、不部分生成。
- 报告仅证明本次采用内容，不新增实际回收、返送、收费或账单动作，不锁定受付／作业。技术生成或保存失败不得伪造成功版本。

## 3. 已确认版式

| 范围 | 当前有效规则 |
|---|---|
| 纸张／字体 | A4纵向，沿用单台点检报告的Noto日文字体 |
| 字号／粗细 | 主标题18pt；客户名称、御中、明细标题及表格主要内容14pt，按原件加粗；製造番号与返却日的值统一14pt（2026-10-17最新裁决，替代返却日12pt）；正文、PROP落款及底部说明11pt |
| 栏目／顺序 | 左右两组「製造番号／返却日」；按小番号升序，每页先左栏从上到下，再右栏从上到下，满页续页；不改为通知的左右逐行排列 |
| 数量与空白行 | 不限制最多20台；产品较少时保留明细区基本高度及未用空白表格行，三条说明放在表格后 |
| 长编号 | 左右同行保持一致高度，任一侧换行则两侧同行同步增高、横线对齐；超出续页，不缩小文字硬塞，不截断编号或产品清单 |
| 续页识别 | 续页保留报告标题、大番号和发行日；明细跨页重复左右两组表头；页脚居中显示当前页／总页数 |
| 说明与PROP | 三条说明逐条保持完整段落，自然接续，不强制仅在末页；PROP信息不逐页重复 |
| 样稿核对 | 页边距、栏宽、间距及基本高度的具体尺寸参照原件，在后续正常及多台／长内容样稿中目视核对，不视为新增字段裁决或已通过PDF验收 |

## 4. 版本、失败与删除边界

回收与报废分别连续计版；不与单台点检报告共用版本。已成立版本保留本次采用内容与所选清单；修改大番号、受付日、产品编号、计划、字典或合法删除小番号不回写历史。预览／下载／打印使用同一版本内容；生成失败不留下成功版本或因假报告阻断删除。

回收报告只保护所属大番号，不额外阻断无自身阻断的小番号或空包裹删除；即使产品均已合法删除，大番号及报告历史仍保留。生成不代表实际回收／报废／返送，不锁作业。报告保存方式、受控模板绑定及PDF渲染技术方案留在OpenSpec，不在本字段表规定表结构或PDF字节持久化。

## 5. 裁决替代关系与剩余材料

- **缺项校验已裁决**：2026-10-17用户明确沿用单台点检报告规则，发行日可清空，抬头、PROP等内容缺失不阻断生成，缺失处留空，不自动补其他来源。该裁决替代此前“发行日清空及其他内容缺项仍待确认”的状态；历史讨论保留，不追溯声称相关实现或验证已通过。具体规则见§1及RC05／RC06。
- 未收到客户回收专用字段核对表。当前正式字段核对以本文为准，不补造客户Excel字段清单。
- 具体尺寸与真实PDF样稿仍待核对；报废报告模板待提供，不能以本报告推定其字段或版式。
