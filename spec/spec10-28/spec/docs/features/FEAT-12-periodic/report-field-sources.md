# 两类案内 PDF 字段来源与冻结对照

本文件是 [FEAT-12 正文 §8.9](spec.md#89-正式案内报告模板与字段2026-10-08用户裁决) 的配套核对说明，同时适用于 FEAT-13 的历史案内显示。按 2026-10-09 已确认规则整理；单元格定位及示例版式见 [正式附件](assets/reports/README.md)。本表不代表字典已初始化或真实创建链路已运行通过。

## 1. 取值总则

新建案内从业务数据、业务字典和员工本次输入形成完整快照，并绑定本次采用的不可变模板。首次完整渲染成功、事务提交后案内成立。历史 PDF 只读取原快照和原模板，不重新读取当前客户、产品、字典或当前模板参数补值。

字典管理的是可维护的业务值；模板管理的是固定文字和排版；系统参数只指定新案内采用哪个已部署模板。内部備考单独保存、可修改，不进入 PDF，也不属于永久冻结的正式内容。

- 金额和 PROP 信息取正式创建时实际采用的字典值并冻结；不新增客户联系方式输入，不增加邮箱字段。
- 费用说明在创建准备时读取默认值，员工可编辑；成立时冻结本次最终提交文字，不以最新默认值覆盖输入、不回写字典。下一次新建重新取默认值。
- 廃棄仅使用上述六项 PROP 信息，不因点检专用金额、部门或说明缺失而阻断。
- 所需字典缺失、重复、停用或空白应明确报错，不静默使用模板示例值。已取得并编辑的费用说明不因默认项随后停用而否定；金额及 PROP 信息仍在正式创建时校验。
- 千位分隔、円、税別、／着等格式和单位属于模板；金额值属于字典。本功能不计算账单总价或产生收款事实。

## 3. 业务数据与系统计算

| 内容 | 来源与采用规则 | 历史 PDF |
|---|---|---|
| 客户编号 | 本次下单方客户主体编号；不是订单号、製造番号或 Excel 查找键 | 使用冻结编号 |
| 宛名公司 | 下单方为一级公司时取该公司当前主档名称；为支店时取上级公司当前主档名称 | 使用冻结名称 |
| 宛名支店 | 下单方支店当前主档名称；一级公司下单留空，不取納品先补入 | 使用冻结名称／空值 |
| 納品先可选名称 | 所选产品当前关联订单保存的納品先快照；最终由员工选择抬头，不任取首台产品 | 使用本次选定并冻结的抬头 |
| 製造番号 | 所选产品；按製造番号升序、产品 ID 辅助排序 | 使用冻结编号和顺序，不按当前档案重排 |
| 点检年次 | 对象月与当前生命周期基准计算第1～4年目，不按发行日计算 | 使用冻结年次 |
| 廃棄期限年月 | 当前生命周期基准月加5年，显示 YYYY年M月 | 使用冻结期限；不是实际报废日期 |
| 点检产品名称默认值 | 排序后首台产品当前档案的对外产品名称；可有不同产品名称，不自动拆单 | 使用本次最终编辑名称 |
| 案内番号 | 系统按正文既定编号规则生成 | 保留原号；重渲染不换号 |
| 文件名 | 按通知类型和案内番号形成并冻结 | 预览、下载使用冻结文件名 |

生命周期基准沿用首次出货及其已确认更正规则；模板保留的「购买日基准」说明不改变系统计算口径。生成廃棄案内不生成真实报废事实。

## 4. 员工本次选择或输入

| 项目 | 初值／规则 | 保存与 PDF |
|---|---|---|
| 对象产品 | 初始全部不勾选，员工主动选择 | 冻结最终通过资格复核的产品集合与顺序 |
| 納品先抬头 | 可不选；选择不限制或改变产品集合 | 同下单方主体显示「貴社」，其他显示选定名称，未选留空；按主体身份而非同名判断 |
| 発行日 | 默认日本当天，只允许当天及之后 | 冻结所选日期；历史不使用当前日期 |
| 点检产品名称 | 默认值见上表，允许编辑统一名称 | 冻结最终文字，不修改产品档案；廃棄不新增此项 |
| 点检费用说明 | 业务字典默认值，允许编辑 | 冻结最终文字；廃棄不新增此项 |
| 内部備考 | 可选内部记录 | 独立保存、允许后续修改，始终不进入 PDF |

## 5. 版本化模板负责的内容

| 内容 | 规则 |
|---|---|
| 首页及续页标题 | 保存于各版本模板内，纳入资源摘要；不能由会变化的通用标题映射替代 |
| 固定正文 | 问候语、购买日说明、寄回注意事项、廃棄産廃警告等按已选 Excel 保留；点检费用说明是上一节的动态文字，不在此硬编码 |
| 表头与标签 | 製造番号、年次、廃棄日等标题、敬称、金额单位及税别等固定措辞 |
| 纸面清洗选项 | 要／不要空框及填写说明；不读取或创建系统清洗状态，奇数台右侧空位不画假产品选项 |
| 排版 | A4 纵向、日文、左右两台逐行排列、字号粗细、列宽、间距、重复表头、续页识别信息和页码 |
| 分页 | 按实际高度；整行放不下移至下一页，注意事项保持段落完整，不固定每页16／20台 |

模板 HTML、CSS、固定文案及实际使用图片按版本完整保留，不覆盖已使用版本。公共开源字体统一复用，不为每份模板重复管理；字体或渲染库升级需要回归历史模板，不承诺 PDF 字节、换行或页数永久不变。

## 6. 系统参数：选择模板，不承载报告正文

| 参数键（当前技术映射） | 用途 | 初始标识 |
|---|---|---|
| `prop.notice.inspection.template` | 新点检案内当前模板 | `inspection-v1` |
| `prop.notice.disposal.template` | 新廃棄案内当前模板 | `disposal-v1` |

复用系统管理的参数设置页面，值是已部署模板标识，不是任意路径或 URL。一次创建确定一次版本，途中切换不影响该次操作；历史案内和已成功请求重试沿用原绑定。参数无效、资源缺失或摘要不符时明确失败，不回退最新模板。两条参数不计入上述11项业务字典。

## 7. 后续校对要点

- 新建：分别核对客户主档、订单納品先快照、产品排序与生命周期计算、11项字典的适用范围及可编辑字段。
- 冻结：更改主档、字典或当前模板参数后，旧案内仍采用原业务值和模板；内部備考修改不影响正式 PDF。
- 模板：两类首页／续页标题、固定文字和布局均属于绑定版本；动态费用说明不得被模板覆盖。
- 历史：缺少旧模板或渲染失败只报错和重试，不补当前值、不换号、不重复创建。成立后的「表示」打开预览，下载／打印使用该次 PDF。
- 验证状态独立记录于当前 Change；本对照文档不替代源码评审、真实业务链路、浏览器或设备打印验收。
