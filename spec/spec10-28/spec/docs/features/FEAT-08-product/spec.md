## 1. 模块概述

本模块覆盖产品建档后的统一管理：产品列表的查询与筛选、产品详情的查看与维护、产品删除。产品在衣体入库时成立（见 FEAT-05 衣体入库）；本模块是员工了解「这台产品现在是什么状态、经历过什么」的统一入口。

```text
产品（衣体入库时成立，见 FEAT-05 衣体入库）
  ├─ 基本信息（製造番号、对外名称、衣体规格、生命周期基准月…）
  ├─ 当前部件（衣体 + 气囊 + 传感器 + 发生器位置 1/2）
  ├─ 生命周期（第 1～5 年点检/报废计划与实际记录）
  └─ 相关业务历史（生产、出货订单、点检维修、部件版本、返送去向）
       ↓ 下游读取
  订单／出货 → 受付／作业 → 返送／回收／报废
```

## 2. 页面构成

| 页面 | 导航位置 | 主要作用 |
|---|---|---|
| 产品列表 | 产品管理 → 产品列表 | 查询、筛选全部产品；进入详情；删除产品 |
| 产品详情 | 产品列表 → 查看详情 | 查看基本信息、当前部件、生命周期、业务历史；部件操作；资料存放路径录入 |

质检工作台见 FEAT-07 质检；部件追溯见 FEAT-09 部件追溯。

导航明确：一级「产品管理」为目录，二级为「产品列表」「部件追溯」，产品详情仍为列表进入的隐藏页面。目录不要求同时拥有两个子页面权限：仅产品权限只显示产品列表，仅追溯权限只显示部件追溯，两者都有显示两页；沿用既有页面权限与角色授权，不新增目录业务权限或扩大子页访问。

## 3. 资料项目与规则

### 3.1 产品

| 资料项目 | 必填 | 规则 |
|---|---:|---|
| 製造番号 | 是 | = 衣体编号，入库时确定，终身不变；更换衣体不改变 |
| M番号 | — | 产品成立时按全系统单调递增序列配发；删除后不复用、允许空号；不在任何界面显示（含搜索等输入入口的提示与匹配键） |
| 对外产品名称 | — | 首次正式发货时按订单采用；之后可通过名称更正事件更新；无事件时显示「未命名」 |
| 衣体规格 | — | 读取当前衣体的最新资料规格（建档时内容 + 最近一次资料更正）；实物更换不自动改变系统衣体资料；资料更正后列表与详情同步变化 |
| 生命周期基准月 | — | 由首次实际发货的月份确定；首次寄送日期更正时同步更正，跨月亦同步改变；未出货或解除关联时选择解除基准月后为空 |
| 首次质检通过日 | — | 首次生产质检通过事实的日期；产品是否已取得首次生产质检资格由产品主档的明确标记判断，不以日期或质检记录存在性代替 |
| 首次出货日 | — | 首次正式发货的日期；首次寄送日期更正时同步更正；解除关联时选择解除基准月会同时清空此日期；无首次出货日时显示「待首次出货」 |
| 资料存放路径 | — | 员工手动录入的 NAS 路径，仅作记录展示 |

产品自身不设置固定的「业务类型」，不区分销售产品、租赁产品或替代产品，也不在首次发货时为产品写入该属性。任何产品均可用于销售、租赁或替代订单；销售／租赁／替代是订单类型，不是产品自身属性。此规则仅取消按产品固定业务类型限制订单用途，不取消产品状态、当前订单关系等其他业务约束。

### 3.2 生产阶段

产品的生产阶段由事实自动确定：

| 阶段 | 含义 |
|---|---|
| 在制 | 尚未满足首次质检最低构成——衣体、气囊、传感器、发生器位置 1 四项中有任何一项未安装（发生器位置 2 始终可空，不影响判断；最低构成定义见 FEAT-07 §3.2） |
| 待质检 | 已满足最低构成，尚未质检通过 |
| 已完成质检 | 产品主档“首次生产质检已通过”标记为通过；之后拆除必需部件、更换、返厂、维修或报废不自动撤销该事实，也不退回在制 |

存量首次质检资格按 FEAT-07 §3.1 认定：已有完整有效质检事实的产品不因缺少对应履历事件而失去资格；只保留差异说明，不补造事件。首次通过日仍取原质检事实，产品删除仍按已有质检记录阻断；标记不取代这两项事实读取。

### 3.3 产品状态

| 状态 | 含义 |
|---|---|
| 已报废 | 已有正式报废事实。报废只终结产品与衣体编号（製造番号）；气囊／传感器／发生器部件个体不随之报废，解除绑定后可继续用于其他产品（与作业管理报废确认、删除产品部件个体保留同口径） |
| 已关联订单 | 存在当前有效的订单关系 |
| 未关联订单 | 无当前有效的订单关系 |

## 4. 产品列表

### 4.1 页面作用

查询与筛选全部产品（含在制、待质检、已完成质检），进入产品详情，删除不再需要的产品。

### 4.2 页面入口与去向

- 入口：产品管理 → 产品列表。
- 去向：单件查询与部件反查命中后均留在产品列表展示结果，由员工点击行内「查看详情」进入产品详情，不自动跳转。
- 从当前列表结果进入详情后返回，恢复进入详情前最后一次成功生效的查询模式、筛选条件、每页条数和页码，并按该上下文重新读取列表。尚未提交或提交失败的输入草稿不作为返回上下文。直接首次进入或从导航重新进入不带查询上下文的产品列表时仍使用默认范围查询；刷新带有已生效查询上下文的列表地址时恢复该上下文。

### 4.4 展示信息

- 筛选区：
  - 筛选方式页签（胶囊样式）：范围查询（默认）／单件查询／部件反查。
  - 范围查询：编号前缀＋起始～结束数字、生产阶段下拉（默认已完成质检）、首次出货状态下拉（全部／待首次出货／已首次出货）。
  - 单件查询：製造番号输入框（回车或查询按钮触发，命中后在列表展示该产品，不自动进入详情）。
  - 部件反查：部件编号输入框（气囊／传感器／发生器编号，命中后在列表展示当前绑定产品，不自动进入详情）。
- 表格列：
  - 产品：製造番号（粗体，单行）。
  - 生产阶段：在制（灰）／待质检（橙）／已完成质检（绿）标签。
  - 对外名称／衣体规格：第一行对外产品名称（未命名显示「未命名」弱化），第二行衣体规格文本。
  - 当前业务归属：第一行订单号＋订单类型标签（已取消订单标注「（已取消）」），第二行下单方名称；无当前关系显示「无当前订单」。
  - 产品状态：已报废（红）／已关联订单（蓝）／未关联订单（灰）标签。
  - 当前组成：三行——气囊编号、传感器编号／固件版本、发生器编号（位置 1／2 有则斜杠连接）；未安装显示「-」。
  - 首次质检通过日：日期或「-」。
  - 首次出货：日期或「待首次出货」。
  - 操作：「查看详情」＋「···」菜单（含「删除产品」）。
- 排序：按衣体实际确认入库、产品建立时间倒序；时间相同按产品内部身份倒序，保证分页顺序稳定。排序在数据库分页前完成，筛选后仍沿用同一口径。制造编号、资料更正、编辑、组装和质检不改变该时间或排序位置；删除后同编号重新入库形成新产品，按新的入库时间排序。本规则只适用于产品列表，不改变组装、质检或部件追溯页面顺序。
- 分页：默认20条/页，可选10／20／50／100条，底部显示真实总数；切换条数回第1页，保留筛选条件。

### 4.5 功能

- **范围查询**：输入前缀与起止编号后点「查询」→ 列表按范围收窄；起止均填写才生效，否则清除范围条件。
- **生产阶段／首次出货筛选**：下拉选择即时生效。生产阶段初次进入默认「已完成质检」；清除后显示全部。
- **单件查询**：输入完整製造番号，回车或点「查询」→ 命中后留在产品列表，展示该产品的完整列表行及匹配总数；即使只有一条结果也不自动跳转，点击该行「查看详情」才进入产品详情。未命中时留在列表展示空结果，并提示「未找到该产品编号」。
- **部件反查**：输入部件编号，回车或点「查询」→ 命中后留在产品列表，展示当前绑定该部件的产品及匹配总数；即使只有一条结果也不自动跳转，点击该行「查看详情」才进入产品详情。未命中时留在列表展示空结果，并提示「未找到绑定该部件的产品」。仍只查询当前绑定，不匹配历史绑定。
- **重置**：清空起止编号、单件、部件输入与范围条件，首次出货恢复全部；生产阶段、编号前缀与查询模式保留当前值。
- **查看详情**：进入产品详情页。
- **详情返回**：返回产品列表时恢复进入详情前最后一次成功生效的查询模式、筛选条件、每页条数及页码；查询或翻页失败不覆盖此前已生效的返回上下文，未提交输入也不随详情往返保留。重置只有在查询成功后才成为新的返回上下文。
- **删除产品**（··· 菜单内）：
  - 点击后先校验阻断条件；存在阻断 → 弹窗一次性列出全部阻断原因，不执行删除。
  - 无阻断 → 二次确认弹窗，说明「产品与衣体将退出当前有效业务范围，原身份及绑定、组装、资料更正历史保留；非衣体部件不删除，M番号不复用，衣体编号可重新入库」。确认后执行删除；取消不改变数据。

### 4.6 校验与反馈

- 删除的阻断条件（任一命中即禁止删除）：
  - 当前仍绑定气囊／传感器／发生器部件（提示先解除绑定）；
  - 已存在质检记录；
  - 已存在出货记录；
  - 已存在受付记录。
- 出货记录按既有记录范围判定，包含准备中的出货记录，不得缩小为仅正式寄出；不得增加其他删除阻断条件。

- 阻断弹窗逐条列出全部命中原因，员工可据此逐项处理。
- 删除确认弹窗说明删除后果；确认后行即时从列表消失。

### 4.7 页面产生的数据

- 删除产品 → 产品及随其删除的衣体退出当前有效列表、选择与业务操作范围；原产品与衣体身份及完整历史数据继续保留。仍存在的关联业务历史继续在其原有展示位置显示原本关联的产品／衣体编号、采用资料与事件内容，不因删除丢失，不以孤立 ID 或删除日志代替，也不得因制造编号被复用而改指新对象；不要求把原对象的全部历史新增展示到其他产品、部件或业务页面。非衣体部件档案及其在本产品或其他产品上的历史均保留。不要求新增已删除产品查询页、历史检索、回收站、恢复或指向已删除档案的导航入口。
- 删除衣体后，该衣体不再计入对应入库记录的当前有效成员；无有效成员的入库记录不再作为有效记录展示，历史登记信息仍保留。
- 衣体制造编号可重新入库，新登记产品和衣体为独立对象，不继承旧对象历史；M番号不复用。当前档案删除与历史身份保留同时成立，不指定软删除、归档表或历史快照等实现。

- 查询、筛选、重置 → 不产生业务数据。

## 5. 产品详情

### 5.1 页面作用

查看一台产品的完整档案：基本信息、当前部件构成、生命周期计划与实际、全部业务历史。在制／待质检产品提供补录部件入口；衣体提供更换入口。

### 5.2 页面入口与去向

- 入口：产品列表行内「查看详情」；单件查询／部件反查命中后先在列表展示，由员工点击「查看详情」进入。
- 详情查询只在有效产品详情上下文且产品ID合法时发起；返回列表、关闭详情标签或离开时不得请求undefined/空ID。有效产品切换重新加载，迟到响应不得回填已离开的产品；NAS草稿隔离与保存规则不变。
- 去向：无页面间跳转（历史中的订单号、番号均为纯文本）。

### 5.4 展示信息

- 页头：製造番号为主标题，带返回按钮。
- 阶段提示条（仅在制／待质检显示）：
  - 在制：提示缺少的部件名称，可在下方当前部件中补录。
  - 待质检：提示已满足最低构成，请前往质检工作台完成质检登记。
- 基本信息（七项，前六项按三列栅格排列，资料存放路径独立一行）：
  - 製造番号、对外产品名称（未命名显示「未命名（首次正式发货时按订单采用）」）、衣体规格（允许多行）、首次质检通过日、首次出货、生命周期基准月、资料存放路径（展示已保存值，空值显示「—」，旁边提供「编辑」）。
  - 不显示产品「业务类型」字段、销售／租赁标签或该字段的「未确定」占位；删除字段后不保留空标签或专用空格。
- 生命周期（表格，未出货时显示空状态「首次出货后生成生命周期日程」）：
  - 固定 5 行：第 1～4 年定期点检、第 5 年报废计划。
  - 计划年月由生命周期基准月推算：1年目 = 基准月 + 1 年、2年目 = 基准月 + 2 年、依此类推；5年目报废计划 = 基准月 + 5 年。出货当年无年次。
  - 实际记录：已有对应受付或报废事实时显示「已计入 · 日期」或「已报废 · 日期」；无记录显示「尚无实际记录」。
- 当前部件（表格，固定 5 行：衣体／气囊／传感器／发生器位置 1／发生器位置 2）：
  - 部位（粗体）、当前编号（等宽，未安装显示「未安装」）、固件版本（仅传感器行显示蓝色标签，其余显示「-」）。
  - 操作列见 5.5。
- 相关业务历史（5 个页签，统一时间线展示，默认「全部」页签）：
  - 每条记录固定三部分：事件名称与核心内容（第一行）、操作人（第二行弱化，显示源记录实际操作人；系统自动事件显示 system；历史无值沿用 system 兜底，不据此推定事件来源）、业务实际发生时间（左侧时间列，倒序）。

  - 各页签事件范围见 5.6「相关业务历史」。

### 5.5 功能

- **当前部件操作**（按部件类型区分）：
  - 衣体：「更换衣体」→ 确认弹窗「请确认线下已完成实物更换。产品、製造番号、系统衣体身份与绑定保持不变，确认后登记更换衣体事件。」确认后实际记录事件；取消不产生事件，不引导前往组装工作台绑定新衣体。
  - 气囊／发生器：「更换」「拆除」。
  - 传感器：「更换」「版本升级」「拆除」。
  - 未安装部件（仅在制／待质检产品显示）：「补录」。
- **更换部件（仅气囊／传感器／发生器）**：弹窗选择部件资料（默认带出旧部件当前资料，可切换）＋输入新部件编号（传感器从 FEAT-03 当前启用项中选择固件版本）→ 结束旧关系并建立新关系；发生器更换保持原安装位置。新编号已建档时校验资料一致性（不一致时提供确认更正选项）；未建档时允许首次使用时建档（按所选资料）。
- **拆除部件**：确认弹窗（说明结束当前安装关系、部件恢复空闲、历史保留）→ 确认后拆除。
- **版本升级**（仅传感器）：弹窗从 FEAT-03 当前启用项中选择新版本 → 追加版本记录，不覆盖历史。已采用后停用的版本继续在当前部件和历史中显示原值，但不再作为新的选择项。
- **补录部件**（在制／待质检产品）：点击对应槽位的「补录」按钮，弹窗选择部件资料＋输入编号（传感器从 FEAT-03 当前启用项中选择固件版本）→ 建立绑定到该槽位，编号首次使用时建档。发生器位置 1／2 各有独立补录按钮，点哪个位置就补录哪个位置，弹窗内不再选择位置。
- **资料存放路径**：展示已保存值，点击「编辑」打开专用小弹窗，明确点击「保存」提交或「取消」放弃；不再失焦或回车自动保存。仅作记录展示，不提供打开或校验。
- **资料不一致确认**：更换或补录时，输入的编号已在系统中建档且该编号当前资料与弹窗中选择的资料不一致 → 弹窗内显示确认区，说明该编号当前资料与所选资料；员工可选择「以所选资料为准」继续执行（同时追加一条资料更正记录，从旧资料更正为所选资料，不覆盖旧值），或「取消」放弃本次操作。产品详情与组装工作台共用同一套冲突处理逻辑。

### 5.7 校验与反馈

- 更换部件时新编号已安装在其他产品 → 报错提示，不执行。
- 更换或补录时未选择部件资料／未输入编号 → 弹窗内校验提示，不关闭。
- 拆除确认前必须二次确认。
- 阶段提示条引导未完成组装或未质检的产品前往对应工作台。

### 5.8 页面产生的数据

- 更换非衣体部件 → 结束旧绑定、建立新绑定，产生更换操作记录；新编号首次使用时建立部件个体。
- 更换部件时接受资料不一致确认 → 追加一条部件资料更正记录；更换传感器时记录新安装关系对应的固件版本；拆除后旧部件恢复空闲，历史记录保留。
- 拆除部件 → 结束当前绑定，产生拆除操作记录。
- 版本升级 → 追加一条传感器固件版本记录（旧版本 → 新版本）。
- 补录部件 → 建立绑定与安装操作记录；编号首次使用时建立部件个体；传感器同时追加初始固件版本记录。
- 更换衣体确认 → 登记“更换衣体”事件，保留原有事件时间与操作人规则。更换衣体只登记线下实物更换事件；产品身份、製造番号、系统衣体身份及现有绑定均不变，不创建新衣体档案、不解除旧衣体绑定，不产生可删除的换下衣体对象。换下实物线下报废，系统不登记其报废过程、不触发产品报废；衣体资料不自动变化，资料错误仍通过既有资料更正机制处理。
- 资料存放路径保存 → 更正产品的资料存放路径字段。

**档案查找范围**：本模块按编号查询或选择待安装部件时，只匹配当前有效档案；“未建档／首次使用”包括旧同编号档案已按规则删除后重新登记，不表示复用旧身份。按原身份发起对已删除部件的安装、资料更正或固件升级均不得执行。

### 4.8 分页与空前缀范围补充（2026-09-28）

- 分页默认20条，可选10／20／50／100条；切换条数回到第1页并保留筛选条件，显示真实匹配总数，通过翻页访问全部结果，不设100件总结果上限。单页最多100条，由服务端限制；不能通过自行传入更大条数绕过。
- 范围筛选的前缀可空：有前缀时按前缀与起止数字组成完整编号；空前缀时仍按起止数字筛选纯数字编号，不取消范围条件。起止须同时填写、均为数字、位数一致且开始不大于结束，严格保留前导零和位数；半填或非法范围提示错误、不扩大查询。产品列表起止均为空时可不限制编号范围，组装和质检的范围筛选须填写起止。

### 5.9 资料存放路径编辑弹窗（2026-09-28 最新裁决）

- 默认展示已保存路径，空值显示「—」，旁边提供「编辑」。点击后打开标题为「编辑资料存放路径」的小弹窗，带出当前产品已保存值，输入提示「可从 NAS 复制路径到此处」，底部提供「取消」「保存」。
- 只有明确点击「保存」才提交；失焦或按 Enter 不自动保存。取消、关闭图标、Esc或遮罩关闭在非保存状态下等同取消：放弃本次输入，不修改已保存路径。
- 保存中显示 loading，禁用输入、重复保存和所有关闭方式。成功后更新当前产品路径并关闭弹窗；失败后弹窗保持打开、保留输入、显示错误并恢复编辑，允许重试或取消。
- 弹窗编辑期间不能操作背后的换衣体、部件保存、拆除或固件更新入口；一般详情刷新不得重置已打开弹窗中的输入。取消后再次打开，从已保存值重新开始；不同产品之间不得沿用草稿或回填旧产品响应。
- 路径仍可留空，仅保存文本，不访问或校验 NAS。本裁决取代页内输入框及失焦/回车自动保存要求；旧原型此处以正文为准，其他详情布局与业务规则不变。

## 6. 跨页面统一规则

- **M番号**：产品成立时配发，删除后不复用，不在任何界面显示（含列表、详情、历史、订单、出货，以及搜索等输入入口的提示与匹配键）。
- **製造番号不变**：更换衣体不改变製造番号；产品身份终身不变。
- **产品创建唯一入口**：衣体入库（见 FEAT-05 衣体入库）；组装、详情补录不创建新产品。
- **删除与编号**：删除产品后其 M番号不复用；衣体製造番号允许重新入库。新产品与新衣体身份独立，不继承原对象历史；历史引用不得因编号相同改指新对象。当前有效列表、查找和选择不包含已删除对象。
- **生产阶段**：由部件构成与质检事实自动确定；列表与详情显示一致。

```text
产品列表、产品详情、产品删除 → 本模块
产品创建（衣体入库）→ FEAT-05 衣体入库；部件组装 → FEAT-06 部件组装；部件资料 → FEAT-02 部件资料
```

明确不做：

- 产品自身固定业务类型的设定、展示或首次发货写入；订单类型仍由订单模块管理；

- 在制品独立管理页（在制／待质检／已完成质检为产品的生产阶段，见 3.2）；
- 产品作废、恢复、回收站及失效状态（产品删除不新增中间状态）；
- 当前业务归属大卡（订单归属通过「出货与订单」页签查看）；
- 对外名称设定／更正按钮（名称事件由发货采用与名称更正事实产生）；
- 直接改写既有编号的功能（误建档或编号录错可在满足既有删除条件后删除错误档案，再按 FEAT-05／06 重新登记）；
- 产品整体档案的编辑弹窗（仅资料存放路径提供专用编辑弹窗，其余字段仍由业务事实产生）；
- 历史中的跳转链接（订单号、番号均为纯文本展示）；
- 解除当前订单关联入口（统一由订单模块处理，见 FEAT-10 订单管理）；

### 单件查询与部件反查留在列表（2026-10-24 用户裁决）

单件查询、部件反查通过查询按钮或回车触发后，命中结果均在产品列表展示，即使只有一条也不自动进入详情；员工点击行内「查看详情」才进入对应产品详情。未命中仍留在列表展示空结果及原提示。此裁决替代此前“命中直接进入详情”的交互，不改变完整製造番号匹配、部件当前绑定范围或其他筛选口径。详情返回时只恢复最后一次成功生效的模式、条件及分页，未提交或失败草稿不作为返回上下文；具体实现与验证状态在对应Change记录，不写入本正式规则。
