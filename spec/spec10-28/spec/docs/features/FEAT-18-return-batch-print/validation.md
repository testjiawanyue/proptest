# FEAT-18 返送批量打印 Validation

依据 [spec.md](spec.md) 验收。本轮为静态核对稿，尚未执行浏览器实测、自动测试或构建。

## 1. 返送批量打印面单

### VAL-01 列表范围

操作：进入「返送批量打印」，核对列表内容。

预期：只显示准备中（未确认寄出）的返送面单；已确认寄出的不在列表内；表头依次为来源单号／寄送记录号（上行为大番号、下行为返送编号）、收货单位（上行为客户、下行为联系人）、产品摘要（製造番号以「、」连接）、台数、收件地址（第一行邮编、第二行地址）、面单张数（默认 1）、操作（修改工作单）；无数据时提示「当前没有准备中的返送寄送」。

### VAL-02 快递公司语义

操作：切换顶部快递公司；核对勾选状态。

预期：切换只改变本次打印模板，不清空勾选、不筛选列表。

### VAL-03 修改工作单刷新

操作：对某笔点击「修改工作单」，在抽屉中取消勾选一台产品后关闭。

预期：抽屉关闭后本页列表刷新，该笔产品摘要与台数随最新内容更新。

### VAL-04 批量打印结果

操作：勾选两笔、分别设 2 张与 1 张，顶部选择佐川急便，点击「批量打印面单」；其中一笔原快递公司为ヤマト運輸。

预期：第一笔本次出单产生一个面单新版本（2 张复印共用同一版本）、第二笔产生一个面单新版本（1 张）；本批下载一个佐川Excel工作簿、含3个面单工作表，不逐Sheet产生版本。模板与寄送记录均为佐川急便（原ヤマト運輸的记录被改写为最近一次实际使用值）；提示「已生成 3 张佐川急便面单（打印不登记寄出）」；两笔仍为准备中、产品清单不变、不产生寄出事实。用户在桌面Excel一次打印整个工作簿、人工逐张放纸，系统生成提示不冒称打印已完成。

### VAL-05 未选择不可用

操作：不勾选任何寄送。

预期：「批量打印面单」按钮不可用；汇总栏显示「已选寄送 0 笔｜汇总产品 0 台｜预计打印{快递公司}面单 0 张」。

### VAL-06 字段、格数与固定纸面边界（待实施）

操作：分别对ヤマト、佐川批量生成，按[FEAT-17 VAL-WB系列](../FEAT-17-return/validation.md#val-wb-01-地址快照与本次编辑待实施)核对本笔字段、空值、首台名称、总台数、完整冻结及前缀显示。

预期：同公司一批一个Excel工作簿、每张一个工作表；字段与单笔相同。ヤマト只显示前12个製造番号，佐川只显示前16个，每行4个、先左到右再上到下；超出不显示，不为超出编号增加Sheet或面单，数量仍为本笔全部产品总台数。本页列表摘要仍按原规则显示，不跟随面单显示上限裁剪。不输出面单PDF，不新增本地打印服务；只在预印纸对应位置印文字。打印参数及长文字处理待确认，不用未确认的设置宣称实纸通过；型号／驱动不作为需求或开发阻断项。

## 2. 回归检查

- 本页只处理返送来源，订单发货批量打印在订单模块独立页面。
- 出单只为每笔产生一个面单文件版本（张数为复印份数、共用同一版本），并把每笔被打印寄送的快递公司更新为本次所选公司。
- 已确认寄出的面单永不进入本页。
