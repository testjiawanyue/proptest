# 返送納品書字段对照（2026-10-18确认版）

本表配套[FEAT-17 §3.2.1](spec.md#321-返送納品書字段与基础版式2026-10-18逐项确认)、[模板采用说明](assets/reports/模板-受付返回納品書/README.md)及[VAL-DN验证清单](validation.md#val-dn-01-固定文字与两种编号待实施)。采用与回收报告相同的需求组织方式；不代表文件保留政策相同、已实现或通过验收。原件位置用于定位，不限制内容长度、产品数量或新样式的具体坐标。

## 1. 来源、编辑与冻结

- 对象为本笔返送及其包含产品，同一大番号可有多笔返送。自动字段按本次生成来源读取，可编辑默认值由员工本次最终采用内容决定，不能在生成时用新默认值覆盖人工修改。
- 客户抬头取本笔已保存的返送地址快照；产品对外名称、製造番号取本次产品资料，PROP取业务字典，担当默认取生成操作人姓名。来源不同，不混用大番号当前值、订单或历史文件。
- 所有本次编辑仅进入本次納品書，不回写返送地址、寄送日期、产品、订单、受付、作业、用户或字典。可空字段的空值同样冻结，后续补齐来源不改写历史。
- 正式成功生成时保留完整采用文字、日期、数量、全部产品及编号顺序；之后修改来源／返送清单，不重新计算已生成版本。版本、发行日期、实际生成时间按既有§3.2规则；本次只确认発送日的独立含义，不更改发行日期必填规则或增设打印栏。
- 抬头、PROP、発送日、担当、備考缺失不阻断生成，不补其他来源或样例。首台对外名称来源缺失或本次清空时留空、允许生成，不补其他产品或来源；不将此裁决类推为发行日期等其他字段可清空。真实读取或生成／保存失败与业务字段空值分开，不伪造成功版本。

「発送日」「受注番号」「担当」「商品名」「数量」「単位」「管理番号」等原件标签不因样例含义另行改写。DN05按已确认样式展示「返送番号」，不将原「登録番号」的旧登记号语义继续用于本笔编号。

## 3. 已确认版式与验证边界

| 范围 | 已确认规则 |
|---|---|
| 纸张及区域顺序 | A4纵向；标题→客户抬头与PROP信息→発送日／受注番号／担当→商品信息→管理番号清单→備考 |
| 字体与粗细 | Noto日文字体，字号及粗细参照当前Excel；不因原件标宋体而要求部署该字体 |
| 原件字号参照 | 标题11pt、普通文字11pt；客户抬头12pt加粗；商品名称／数量、発送日12pt；大番号14pt；「様」14pt加粗；管理番号标题10pt、编号值11pt；其他粗细参照原件，不套用回收报告14pt编号规则 |
| 编号网格 | 每行4个製造番号，从左到右、从上到下；不沿原8列、不使用回收报告先左栏后右栏的顺序 |
| 长内容与数量 | 长抬头、地址、名称、编号及多行備考允许换行、增高，放不下续页；完整保留，不缩字号硬塞，不截断，不把原件6行×8格作为产品台数上限 |
| 敬称 | 「様」在客户抬头右侧上下居中，不自动改为「御中」 |

2026-10-18当前离线样式已获用户确认：独立编号标签「返送番号」；「管理番号」四字竖排、右侧每行四编号；商品区与编号区内部边线对齐，普通稿保留六行基本编号空间和纵向留白；「様」保持抬头右侧竖中并按确认稿稍向左移。续页保留标题／返送编号、页脚居中页码、编号侧标题，PROP与商品汇总不逐页重复。长稿为离线分页研究稿，样式确认不代表生产自动分页通过；回收报告的双栏及说明段落不能移植。原件未设纸张、方向、打印区、缩放或手动分页；A4纵向是用户裁决，不是原打印设置。

输出形态已确认：统一采用既有HTML→PDF及PDF预览／下载／打印，不生成Excel。原Excel仅为字段位置、区域顺序及字号／粗细参考，不是运行输出模板；当前离线PDF样式已获用户确认，实际自动分页及运行待验证。文件保存、模板绑定、技术生成方案留在OpenSpec后续方案，不在正式字段表规定存储结构、PDF二进制或在线模板维护。

## 4. 裁决替代关系及边界

- 标题、固定品名、单位、敬称采用原文；原文件夹名称不改变文档标题。原样例客户／日期／担当／数量／产品名／编号不是固定值。
- 原F2登记号区域先讨论过取大番号，最终采用本笔独立返送编号；原「受注番号」最终取大番号，替代人工填写订单号的建议。两种编号不得互换。
- 产品名称最终采用排序后首台产品名称并允许修改，替代按不同名称分组商品行的建议；颜色不从规格文本自动推导。
- 每行4个製造番号替代原件及前次描述的每行8个；原Excel只读保留，不伪造已经另存四列表格的客户原件。
- 旧2026-10-16材料中的「納品書」Sheet、单价／金额、上下联及旧字段表不适用当前「内容明細書」原件；历史分析保留，以本次采用README与正文为现行依据。没有现存客户字段Excel，不补造附件。
- 保持本笔返送版本、准备可按业务删除其所属文件／历史、正式返送不可删除等既有规则。生成不登记寄出、不改变订单、不要求先确认寄出；不增加大番号／小番号正式报告删除阻断。权限、确认寄出等规则仍按FEAT-17，不借需求整理开放实施或其他D范围。

- 2026-10-18输出增量：HTML→PDF替代此前输出待决及Excel下载推荐；字段DN01～15、每行4个及既有版本／冻结／历史不变。
