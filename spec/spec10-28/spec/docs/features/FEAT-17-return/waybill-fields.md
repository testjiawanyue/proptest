# 返送快递面单字段对照（2026-10-18确认版）

配套[正文§3.2.2](spec.md#322-返送快递面单字段与excel输出2026-10-18逐项确认)、[ヤマト原件及采用说明](assets/reports/模板-快递面单-ヤマト送り状/README.md)、[佐川原件及采用说明](assets/reports/模板-快递面单-佐川送り状/README.md)及[VAL-WB验证清单](validation.md#val-wb-01-地址快照与本次编辑待实施)。采用“正文规则＋字段对照＋模板附件＋验证清单”，不代表已实现或实纸通过。

## 1. 取值时点与冻结

- 对象为本笔返送及其包含产品，不取整个大番号下全部产品。默认值从本笔已保存返送资料读取；地址七项只取该笔已保存地址快照，产品对外名称及製造番号取本次产品资料。
- 可编辑字段按员工本次最终采用值输出，允许补充、修改或清空；只进入本次面单，不回写地址、返送、产品、订单、受付或作业。缺失留空，不补其他来源、不阻断生成；不以空值规则掩盖真实读取或生成失败。
- 成功生成时冻结实际采用文字、空值、日期、箱数、配送时段、总数量、所属大番号，以及全部产品身份、完整製造番号及顺序。后续业务变化不改变旧版。显示前12／16个不等于只冻结前12／16个。
- 面单版本、发行日期及实际生成时间沿用正文§3.2；出荷日不是发行日，不因原件没有发行日期栏擅增打印栏。几张复印共用一个业务版本，不逐Sheet计版。

## 2. 字段对照

下表“可编辑／空值”中的“本次”均指仅本次面单，不回写业务。坐标是原Excel材料定位，不能代替尚未确认的实际打印区域及套打位置。

|---|---|---|---|
| WB01 | 郵便番号；C2:D2／D2:H3 | 本笔已保存地址快照的邮编 | 可补充、修改、清空；缺失留空，不补源、不阻断；冻结采用值／空值 |
| WB02 | 住所1；B6:D6／B4:I5 | 地址快照的地址主行，不拼地址补充行 | 同WB01 |
| WB03 | 住所2；B7:D7／B6:I6 | 地址快照的地址补充行，与住所1分别输出 | 同WB01 |
| WB04 | 会社名；B8:D8／B7:I7 | 地址快照的公司名称，不拼納品先名称 | 同WB01 |
| WB05 | 現場名・支店名；B9:D9／B8:I8 | 地址快照的納品先名称，与会社名分别输出 | 同WB01；不当作联系人 |

| WB08 | 品名；E6:G6／J5 | 固定客户原文「ライフジャケット」 | 不可编辑；冻结固定文字 |
| WB09 | 型号／颜色（原表称機種名）；H6:J7／M5:O5 | 本笔产品按製造番号升序、产品ID辅助排序，取第一台当前对外名称；不另拼型号或颜色，不从订单读取 | 可修改或清空；首台缺失留空，不跳取其他产品、不补其他来源、不阻断；冻结本次统一名称／空值 |

| WB12 | 製造番号；E8:L10／J6:Q9 | 本笔全部产品，按製造番号升序、产品ID辅助排序 | 自动带出、只读；冻结全部编号、产品身份及顺序。ヤマト只显示前12个，佐川只显示前16个；每行4个，先左到右再上到下，超出不显示 |
| WB13 | 编号区域；原N10:O10、Q2:T4／M12:P13 | 本笔所属大番号，不取订单号或独立RT返送编号，不另编面单业务编号 | 自动带出、只读，冻结大番号及归属。ヤマト只在原小框N10:O10输出，位置不变；删除Q2:T4大字框及内容，不重复输出（2026-10-19确认）。原件不改写，其他打印参数仍待定 |
| WB14 | 出荷日；ヤマト无对应已确认区／佐川I18:M19 | 本笔已保存的寄送日期，不取生成当天或其他业务日期 | 可修改或清空；缺失留空、不补日期、不阻断；冻结采用日期／空值。显示格式待确认，不自动套納品書格式 |

WB14～16只对应佐川原件，不为统一字段而给ヤマト新增打印内容。原件样例客户、数量、订单键、日期、AM及字段核对Excel中的旧查找公式说明均不是现行业务默认值。

## 3. Excel批量输出与预印纸

- 两家均使用快递公司提供的预印面单纸。系统只在对应位置输出文字，不把预印框线、标签或背景再印一遍；工作人员人工逐张放纸。
- 同一家快递公司的本批面单生成一个Excel工作簿，每张实际面单一个工作表。客户在桌面版Excel中一次选择“打印整个工作簿”，集中提交本批打印；不要求逐个文件点击打印。
- 一笔返送选择N张时，在工作簿中包含N个复印工作表，共用本次同一个面单版本；同一批多笔各自保持所属返送及版本，不因合在一个工作簿合并业务记录。
- 本次选择Excel输出，不同时生成面单PDF，不套用既有PDF预览弹窗，不新增本地打印插件、打印服务或自动连续进纸控制。Excel中的打印预览及实际打印由客户在桌面版Excel完成。
- ヤマト12格（3行×4列）、佐川16格（4行×4列）。超出编号不显示，不为补全超出编号自动续页或增加面单，数量仍为全部产品总台数。

## 4. 待确认的打印设置与验证边界

单张纸实际尺寸、打印区域、方向、缩放、页边距、起印位置及偏移、字号和长文字在固定纸面内的处理、佐川出荷日显示格式仍待确认。尚不能以原件网格范围或默认页边距宣称每个Sheet已能准确印在一张实纸上；也不预设缩放100%、A4或报告类的自动续页规则。

客户后续补充纸张尺寸。打印机型号、驱动不作为需求确认或开发阻断项，也不绑定固定设备；后续实纸时核对当前可用设备与桌面Excel设置的适配，换设备后按需校准。不新增设备登记、固定驱动依赖或以客户提供型号为开工前置条件。Excel可集中提交不等于已验证打印机等待逐张放纸的实际表现。

## 5. 替代关系

- 本文件及正文§3.2.2替代“面单字段全部待定”、PDF输出建议和生成后统一弹PDF预览的旧面单安排；已完成納品書、单台点检及回收报告不受影响。
- 原字段核对表中的订单号查找及订单机型来源，被本笔返送快照／当前产品来源替代；编号区域最终采用大番号。
- ヤマト原核对表“10格”由实际模板12格及本次裁决替代；佐川原核对表“J6-P9”定位未包含合并至Q列的末格，以原模板J6:Q9的16格及本次裁决为准。
- 完整冻结清单但仅显示前12／16个，是已确认显示例外；不恢复全部编号必须打印的早期建议，不改变总台数。
- 现有版本、历史、准备可按业务删除所属文件／正式寄出不可删除、生成不等于寄出及批量出单的承运公司写入规则保持；只读字段的业务归属不因Excel输出变化。本轮仅需求同步，不表示功能已实现、获实施授权或打印验证通过。
