## 1. 返送管理

### VAL-01 列表内容与排序

操作：进入「返送管理」，核对行内容与排序。

预期：每行显示大番号（附受付日期，不显示受付完成标记）、客户（附来件邮编地址）、返送状况（待返送 N 台／已返送 · 可返送 · 共 N 台／未生成报告标签）、返送面单（件数与最新返送编号）；受付日期最早的批次排最前。

### VAL-02 筛选

操作：分别使用大番号、客户名称、地址、受付日范围、返送状况（全部／有待返送／暂无待返送）筛选；重置。

预期：文本类为部分匹配；受付日按范围过滤；返送状况按待返送数量是否大于 0 分流；重置清空全部条件。

### VAL-03 待返送口径

操作：对同一大番号制造以下情形并核对「待返送」计数：计划返回客户且未返送的产品；计划返回客户但已进入准备中面单的产品；计划返回客户且已确认寄出的产品；计划为 PROP回收的产品；已确认回收或报废后又把计划改为返回客户的产品。

预期：第一类和第二类均计入待返送；准备中面单不影响待返送计数（不反映勾选过程）；已确认寄出、计划回收以及本条受付已确认回收／报废均不计入；实际处理后改回返回客户也不恢复待返送计数。与首页口径一致，首页按有待返送产品的大番号数统计，本页按台数统计。

## 2. 返送详情

### VAL-04 产品表内容

操作：进入某大番号返送详情，核对产品表六列。

预期：产品（製造番号＋受付番号连写）；当前计划（返回客户／PROP回收／报废／未定）；点检作业——返回客户显示 完了／作業中（与作业管理同口径），报废已确认显示 廃棄済、未确认显示 —，回收已确认显示 回収済、未确认显示 —；报告书——固定履歴＋生成报告（点检），所有计划及空计划均可生成，履歴仅查看、下载／打印在预览；展开维修报告显示存放路径或 —；实际处理结果显示 报废済／回收済／已返送·编号／面单准备中·编号／未返送。先返送后确认报废的同一产品行同时显示已返送及其返送编号、已报废（日文「廃棄済」），不得相互覆盖。

### VAL-05 就地生成报告

操作：对各类及空计划的产品点击「生成报告」两次，查看履歴；回收／报废计划核对弹窗提示。

预期：仅生成单台点检报告，每次新版本并预览；任何计划均可生成，回收／报废计划提示但不阻断；履歴仅查看，预览下载／打印；不产生返送事实。

2026-10-16补充（待实施）：字段及PDF输出统一按[FEAT-16 VAL-IR系列](../FEAT-16-work/validation.md#val-ir-01-抬头来源与报告内修改2026-10-16待实施)验证。至少从返送入口核对一次起始编号与最新保存值比较、人工修改仅本报告生效、所有内容缺项可生成、A4纵向完整续页、再次生成不继承上版输入及旧版本内容不变。与作业管理共用同一小番号版本序列和历史，不复制另一套报告规则；当前邮件／返送事实不因报告生成而变化。本轮仅需求同步，未执行。

### VAL-06 面单表与入口

操作：核对返送面单卡；点击「生成面单」「继续返送」「查看」，核对详情操作列不显示「印刷／打印」。

预期：面单按创建时间倒序列出；准备中显示「继续返送」，已发出仅显示「查看」，无独立「印刷／打印」；点击「生成面单」只打开新建态抽屉，此时不建立面单记录、不取得返送编号；首次保存、生成文件或确认寄出时才建立准备中面单并取得返送编号。

补充（2026-10-23，待验证）：移除详情表按钮不影响从查看／继续返送进入抽屉；抽屉内面单Excel生成／历史下载、納品書PDF生成／预览／下载及邮件查看仍可达。旧截图操作列不作为恢复无效按钮的依据。

## 3. 返送寄送抽屉（准备中）

### VAL-07 勾选与不可选原因

操作：新建面单，核对产品勾选表；尝试勾选报废済、回收済、已在其他面单（准备中／已确认）的产品。

预期：全部有效受付产品按小番号列出（#／製造番号／受付番号／当前计划／状态）；报废済、回收済、已在其他面单的产品不可勾选，状态标签说明原因（附日期或面单号）；计划为 PROP回收／报废但未正式执行的产品可勾选。

### VAL-08 混装提示

操作：勾选包含计划为「PROP回收／报废」的产品。

预期：顶部提示本次面单包含 N 台当前计划为「PROP回收／报废」的产品，说明面单只是寄送记录、允许混装，请确认实物装运无误。

### VAL-09 保存与校验

操作：不勾选任何产品点击保存；来源大番号无来件地址时点击保存；正常勾选后点击保存。

预期：无产品时保存被阻断并提示（如不再寄出请使用删除）；无来件地址被阻断并提示；正常保存后面单处于准备中，不登记寄出事实。收货单位与地址卡全程只读，无修改入口。

补充（2026-10-23，待验证）：准备中修改产品／物流只保留页面草稿，显式保存才写入。生成文件前若尚未保存或有脏稿，保留“是否保存并继续”；取消无保存／生成，保存失败、冲突或结果未知不继续生成。底部不将草稿称为已自动保存。

### VAL-10 打印不登记寄出

操作：在已保存的准备中面单中选择快递公司，点击「生成面单（2 张）」；点击「打印納品書」，其字段与基础版式按VAL-DN系列核对。另在新建抽屉（尚未保存）中勾选产品后直接点击「生成面单（1 张）」。

预期：已保存面单点击「生成面单（2 张）」产生一个面单新版本（2 张为复印份数、共用同一版本，提示「同一版本复印」），下载包含2个面单工作表的Excel工作簿，预览／打印在桌面Excel完成，不弹PDF预览；「打印納品書」生成一个納品書新版本并沿PDF预览。均不登记寄出、不改变寄送状态。新建抽屉直接生成面单时，会先建立准备中寄送并保存所选产品（此后这些产品不能加入其他面单），再生成文件。面单字段另按VAL-WB系列核对。

### VAL-11 删除准备中面单

操作：对未生成过文件的准备中面单点击「删除」并确认；对已生成多版面单、納品書的准备中面单先取消删除，再确认删除；另核对该准备所属全部文件／邮件版本（如有）及其他业务记录。

预期：二次确认「删除后不可恢复」；取消时准备、清单与文件均不变。确认后无文件、有文件的准备均可删除，准备及所属清单关联、全部文件与邮件版本不保留业务历史；产品解除该准备占用并按原资格恢复可勾选。产品档案、受付、作业、报告、其他寄送及正式履约不受影响。

## 4. 确认寄出

### VAL-12 确认弹窗校验

操作：未选快递公司时打开「补充运单号并确认寄出」；选择快递公司后再次打开；输入重复运单号。

预期：未选快递公司时提示先选择、不得确认；弹窗说明「确认表示本次 N 台产品已经实际寄出。确认后产品清单冻结，不改变订单关系；快递公司、寄送日期与运单号仍可修改」；含计划非返送产品时提示计划保持不变；运单号重复时提示合并。

补充：商品名默认本次清单首台产品当前对外名称，允许本次修改或清空，首台无名称不跳取其他产品；取消不写入本次名称／运单草稿。确认后再次生成邮件时重新取当时默认，不沿用本次改名，不回写产品或订单。

### VAL-13 确认寄出结果

操作：补充运单号后点击「确认寄出并生成邮件」。

预期：登记正式返送事实（不可逆），弹窗关闭；抽屉切换为寄送详情态——产品清单只读附「已确认寄出」，已生成文件卡增加邮件历史并出现运单号维护卡，邮件正文在已生成文件卡查看与复制；返送详情中该批产品实际处理结果变为「已返送 · 编号」。

补充：确认必须与第一份正文真实生成／保存同事务完成；技术执行／存储失败时不得提示成功或留下寄出无正文。模板缺变量／删行、字段空值或内容不完整不阻断寄出。沿现有定点测试能力覆盖实际生成／保存失败，不为本用例新增故障注入或运行环境。

### VAL-14 批次已返送计数

操作：同一大番号分两批寄出不同产品（两张已确认面单），核对批次「已返送」计数；再尝试把已寄出产品加入新面单。

预期：已返送数为两批不同受付产品的合计；已寄出产品不可再勾选（已返送永久退出候选），不存在同一产品被重复寄送的情形。

## 5. 寄出后维护

### VAL-15 属性更正

操作：确认寄出后修改快递公司、实际寄送日期、箱数；核对收货单位与地址卡。

预期：修改即保存并记最后修改人／时间；产品清单不变；既有邮件版本保持不变（不自动更新），点击「生成邮件正文」后按当前寄送信息产生新版本（版本号递增，v1 不被覆盖）；收货单位与地址只读，确认后同样无修改入口。

补充：复用同一返送，确认时修改过商品名后再次生成，采用首台产品当时默认而非前次改名；产品默认名称或当前模板改变后，新正文使用新值，旧版本全文仍不变。

### VAL-16 运单号维护与邮件

操作：确认寄出弹窗中补充两个运单号并确认寄出；在运单号维护卡追加、修改、删除单号后「保存单号」；点击「生成邮件正文」两次，对已生成的邮件版本点击「查看」并复制正文。

预期：确认弹窗补充的运单号与运单号维护卡显示一致（同一份数据）；保存后运单号更新；关闭并重新打开抽屉后，多个运单号仍按多个独立行显示；每次「生成邮件正文」产生一个新版本并打开查看弹窗，历史版本不覆盖；查看弹窗显示该版本生成时间与正文全文，可复制；邮件列表按版本逐行显示，无「按当前内容现算后直接复制」的旁路按钮。

邮件模板定点补充（均未执行，不新增验证体系）：

- 管理员通过现有参数设置调整正文，后续新生成采用已保存模板；初始模板按正文§3.3，无制造编号清单、无四句网站回执。模板仅正文载体，不生成PDF、附件或自动投递。
- 在模板中重复合法变量，两处使用本次同一字段值；删除任意变量／行，或字段无值仍可生成保存，不因内容完整性阻断。未知／残缺占位符原样保留，无专门警告，不执行脚本／表达式、不再次解析插入值。

### VAL-17 统一文件历史与右侧生成入口

操作：在已有文件的准备及确认寄出后，从统一列表查看／下载历史，再从右侧面单、納品書入口生成新版本；准备中不显示邮件。

预期：历史行不显示「新しい版を生成／继续打印」，仅读取原版本Excel／PDF／冻结正文，不新增版本。右侧生成仍递增本类型版本，先按原规则确认保存，取消、失败、冲突／未知时不继续；旧内容、模板绑定不变。跨类型同版本号按类型／记录身份区分，完整倒序清单统一分页，不漏历史。

### VAL-18 不可撤回

操作：查看已确认寄出面单的抽屉底部。

预期：无撤回／作废入口；仅有「关闭并返回列表」。

### VAL-18b 正式返送的删除保护

正式确认寄出后检查界面，再直接调用删除请求。

预期：无删除入口；服务端拒绝删除，返送记录、清单、文件及正式返送事实均保持。不以已打印文件阻断准备删除，不允许接口绕过正式寄出限制。

## 6. 边界回归

- 准备有文件仍可删除，取消无变化，所属关联与全部版本移除；正式寄出后的删除在界面及服务端均被禁止。

### VAL-E1 返送不影响订单

操作：对来自某订单的产品完成一次返送确认，核对订单管理与产品详情。

预期：订单履约数量与订单关系不因返送改变；产品详情的返送历史新增一条已确认记录。

### VAL-E2 已返送产品永久退出候选

操作：对已确认寄出的产品再次新建面单，尝试勾选。

预期：该产品不可勾选，状态显示「已返送 · 编号」；不存在再次返送。

### VAL-E3 客户再次寄回走新受付

操作：已返送产品再次被客户寄回 PROP。

预期：在受付工作台建立新的受付记录（新一轮点检），不能用原受付的重复返送代替；原返送历史保留。

## 7. 回归检查清单

- 打印与寄出始终分离：任何文件生成／打印不登记寄出事实。
- 确认寄出只冻结产品清单；快递公司、日期、箱数、运单号确认后可更正；返送地址建立时取大番号来件地址形成快照，之后始终只读、不随大番号后改。納品書内抬头修改仅进入本次文件，不改变该地址快照。
- 待返送只统计计划返回客户且未实际返送；准备中面单不影响计数。
- 快递公司任一修改路径（抽屉选择／批量打印出单）后，面单印刷公司与系统记录一致。
- 报告生成与返送事实互不影响。
- 已确认寄出无撤回、无作废、无产品清单编辑。
