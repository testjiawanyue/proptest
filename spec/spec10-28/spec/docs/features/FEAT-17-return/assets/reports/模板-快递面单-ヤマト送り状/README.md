## 2. 采用字段与替代内容

- 地址、公司、納品先、联系人及电话只取本笔返送已保存地址快照，分别输出；允许本次补充／修改／清空，缺失留空、不补源、不阻断，不回写业务。电话保留保存格式；联系人不取生成操作人。
- 品名固定「ライフジャケット」、单位固定「着」，不可编辑。名称取本笔产品按製造番号升序、产品ID辅助排序后的首台当前对外名称，可修改／清空，首台缺失留空，不跳取其他产品、不补订单等来源、不阻断。
- 数量取本笔产品全部总台数，只读。编号区域取所属大番号，只读；不取订单号、RT或另编业务流水号。逐字段定位、空值及冻结方式见字段对照WB01～16。
- 製造番号原区域E8:L10，**12格＝3行×4列**；自动只读，按製造番号升序、产品ID辅助排序，先左到右再上到下。只显示前12个，超出不显示，不自动增加面单／续页补清单；数量仍为全部台数。生成冻结全部产品身份、完整编号和顺序，不能只保留可见前缀。
- 原字段核对表写“10格”，由本次12格裁决及原件实际3行×4格替代；编号区域统一取大番号。2026-10-19确认：仅在原小框N10:O10输出，位置不变；输出模板删除Q2:T4大字框及内容，不重复输出。原Excel只读保留，不覆盖修改。
- 原样例值、订单VLOOKUP说明、原表“客户／订单来源”不是现行规则；正式来源及允许修改范围以字段对照为准。

## 3. Excel输出与套打

同一家快递公司的本批面单生成一个Excel工作簿，每张实际面单一个工作表；N张复印对应N个工作表、共用该笔本次一个业务版本，不逐Sheet计版。客户在桌面版Excel一次“打印整个工作簿”，人工逐张放入快递公司预印纸。系统只输出对应位置的文字，不重印预印框线、标签或背景；不同时生成面单PDF、不套PDF预览弹窗、不新增本地打印服务或自动连续进纸控制。

大番号已确认沿用N10:O10原小框位置并删除Q2:T4大字框；其他实际套打设置仍待确认。原件合并区域、行高列宽、字体及留白供后续核对，不推定所有原件非空区域都应打印。

## 4. 已查事实与待定设置

只读检查原模板：有合并区域，无公式；没有已定义打印区域、纸张／方向／缩放设置或手动分页记录。文件页边距为左右0.75英寸、上下1英寸、页眉／页脚0.5英寸，**这些文件值不是客户确认的打印参数**。

待确认：单张纸尺寸、打印区域、方向、缩放、页边距、起印位置／偏移、字号、长文字在固定纸面内的处理及佐川出荷日格式（后者只适用于佐川）。不预设A4、100%缩放或报告类自动续页。

打印机型号及驱动不作为需求确认／开发阻断项，不绑定固定设备、不要求客户必须提供；后续实纸验证记录当时设备与Excel设置并按需校准，设备可能更换。一次提交工作簿的能力不等于已验证当前设备逐张等待人工进纸。

本次仅同步正式需求与验证预期；未编码、未部署、未生成正式面单、未操作Excel或打印机。原件SHA保留，旧材料及结论不追溯改写；实际输出及实纸仍待验证。
