# PROP 业务术语对照表（中文 / 日文）

> 用途：系统 UI 双语化（中文 / 日文）的唯一术语标准。日文以客户原始材料（Excel 台账、打印模板、现场照片、现场访谈整理）中的原文为准。
>
> 阅读说明：
> - **置信度**：术语日文形态的客户材料依据强度。**高** = 能在原始 Excel 台账／正式模板中找到原文；**中** = 仅见于现场照片；**低** = 仅来自现场访谈整理；**自造词** = 客户材料无对应词、系统自建（日文经多轮校验，标注「自造词·校验」）。
> - 同一中文只对应一个日文；客户材料中存在多个写法时，选正式文件中最常用的进「日文」列，其余写进「业务解释」。
> - 日文使用业务系统 UI 简体（〜する／〜確認），不使用敬体（〜ます／〜いたします）。
> - 本表按业务模块分组，模块顺序与系统导航／业务流转一致：客户 → 部件 → 生产・质检 → 订单・出货・寄送 → 定期管理・通知 → 受付 → 作业・报告 → 回收・报废・返送 → 通用。
> - 全角／半角：客户 Excel 原值中的混用、错录变体不在本表规范范围内；本表规定系统 UI 显示形态（片假名统一全角）。

## 凡例

| 列 | 含义 |
|---|---|
| 中文 | 系统中文界面显示词 |
| 日文 | 系统日文界面显示词（唯一标准） |
| 业务解释 | 该词在 PROP 业务中的含义／使用场景／常见别名 |
| 置信度 | 高／中／低／自造词（依据见上） |

## 附：待定／待裁决事项（不影响本表使用，后续需收敛）

1. 「ジャケット」标签语义：部门台账 B 列标签「ジャケット」实值为製造番号，UI 是否改名为「製造番号」待裁决。
2. 「110㎝センサ戻し」字形：原始值为半角片假名「110㎝ｾﾝｻ戻し」，本表暂用全角；保留原文还是统一字形待裁决。
3. 返送／回收编号：客户材料无 RT 类内部编号；「返送」一词为客户现场沟通中文用词，日文 UI 沿用「返送」（低置信度，建议向客户确认日文对应词）。
4. 「管理番号」多义：报废票编号、部门台账关联键（＝小番号）、纸质受付管理 NO. 均称「管理番号」；UI 展示时须带上下文，不单独裸用。
5. 系统自造词（状态标签、按钮、业务分类等）日文已经多轮翻译校验，仍待客户最终确认 UI 用词；语言层面的优化备选已在「业务解释」列标注（如「キャンセル→キャンセル済」「配送希望时间→お届け希望時間帯」）。
6. 低置信度术语的处理原则：访谈来源词（如「返送」）若客户书面材料中另有正式对应词，以书面词为准。
