# FEAT-00 首页看板 Validation

依据 [spec.md](spec.md) 验收。本页为纯统计展示，用例聚焦各卡片口径的正确性与跳转；通过在其他模块构造数据后观察看板数字变化来验证。

## 1. 统计口径用例

### VAL-01 订单一览：租赁／销售／替代分列

操作：在订单管理中分别建立租赁、销售、替代订单，部分发货使其分别处于「未发完」「已发完」状态。

预期：订单一览的「租赁订单」「销售订单」「替代订单」三列分别统计本类型的进行中单数（= 未发完，含一台未发；已发完不计入进行中）；明细显示本类型剩余待发台数合计；已结束订单不计入。

### VAL-02 待办事项：今日要发货与逾期未发

操作：建立三笔仍有剩余待发的订单，预计发货日分别填今天、昨天、不填；其中一笔发完。

预期：「今日要发货」只计入预计发货日为今天且仍有剩余待发的订单，附剩余待发台数；「逾期未发」只计入预计发货日早于今天且仍有剩余待发的订单，单数大于 0 时数字为红色；已发完的订单即使预计发货日已过也不计入；未填预计发货日的订单两项都不计入。

### VAL-03 厂内作业：待清洗／待返送／今日受付

操作：(a) 受付一台要求清洗的产品，登记清洗完成前后各看一次；(b) 受付一批处置决定为返回客户的产品，实际返送前后各看一次；(c) 今天新建若干受付。

预期：(a) 待清洗在登记清洗完成后减 1；产品回收或报废后不再计入。(b) 待返送按大番号计数，批内产品全部实际返送（确认寄出）后该批不再计入；只认实际寄出——返送面单已建立或已打印但未确认寄出的产品，仍计入应返未返；处置决定不是返回客户、或已回收／已报废的产品不使批次计入。(c) 今日受付等于今天新建的有效受付台数，删除的受付不计入。

### VAL-04 今日作业：按工作组、按首次登记

操作：今天在縫製组登记一台作业、再多次修改同一台；在センサ组登记两台；另取一台昨天已首次登记、今天又修改的作业记录。

预期：縫製显示 1、センサ显示 2、其余组显示 0；同一台同组当天重复修改不重复计数；昨天首次登记、今天修改的记录不计入今日（只认首次登记时间）；次日再打开时今天的记录不再计入；作废的作业记录不计入。

### VAL-05 厂内库存：在制品／成品在库

操作：(a) 新建未过质检的产品；(b) 质检通过且当前无订单关系的产品；(c) 质检通过且有未结束订单关系的产品；(d) 受付侧确认回收一台已发货产品；(e) 从订单管理解除一台已发货产品的当前订单关系。

预期：(a) 计入在制品；(b) 计入成品在库；(c) 两者都不计入；(d)(e) 订单关系从任一入口结束后该产品都进入成品在库（不要求重新入库质检）；报废产品不计入成品在库。另核对未通过首次质检但已报废的产品，不计入厂内库存或半成品的在制品数量。

### VAL-06 半成品：在制品／待质检／零件数

操作：构造两台在制品与一台已过质检产品——A（在制品）缺发生器、B（在制品）部件齐全未质检、C 已过质检；A 绑定气囊＋传感器，B 绑定气囊＋传感器＋发生器位置 1／2；另取一个气囊先绑定 A 再解除绑定。

预期：在制品 = 2（A、B）；待质检 = 1（B）；零件数只统计在制品当前有效绑定——气囊 2、传感器 2、发生器 2（B 的位置 1／2 各算一个）；已解除绑定的气囊不计入；衣体不计入；C 的绑定不计入。

### VAL-06a 已报废在制品统一排除

操作：在上述A、B之外，另建未通过首次质检、部件齐全的D，绑定气囊、传感器及发生器位置1／2。通过既有作业管理流程确认D报废，按既有规则解除非衣体部件的当前绑定并保留历史；刷新看板并从半成品跳转。

预期：报废后，两处在制品为2、待质检为1，气囊／传感器／发生器分别为2／2／2，D不计入；跳转筛选也不包含D。D的部件个体与历史绑定保留，首页读取本身不产生解绑、删除或历史改写。非报废A、B正常计入，C仍因已过检排除。无需构造报废后仍保留完整当前绑定的特殊状态，不修改既有报废流程。

## 2. 页面交互用例

### VAL-07 跳转链接

操作：检查六卡全部入口，分别以具备/不具备产品页面权限的用户查看；有权用户点击厂内库存「查看产品」、半成品「查看在制品」。

预期：仅保留上述两个业务跳转。库存进入产品列表原默认已完成质检视图；半成品进入未删除、未报废且未通过首次生产质检的组合筛选（包含组装中与待质检），原有筛选及普通入口默认行为不变。无产品权限时两链接均不显示，汇总仍可见。订单一览、待办事项、厂内作业、今日作业不出现「查看订单」「查看作业管理」「进入受付工作台」「查看返送」或同义日文入口，也不把入口改为数字、标题或整卡点击；厂内作业不保留空按钮栏。加载/失败时保留的两个有权入口仍可用，「再読み込み」是读取重试按钮，不受本次删除影响。

### VAL-08 加载、零值及布局

操作：延迟只读统计响应，分别首次进入、重新进入和刷新首页；再返回全部为0及含非0的完整成功结果。

预期：请求开始即在六块数字区显示骨架及「読み込み中…」，不闪现0或旧数字；卡片框架和已获权限的跳转可用，无整页阻塞或明显布局跳动；成功后统一展示六块真实数字，全0成功与加载、失败明显不同。

### VAL-09 超时与失败

操作：分别模拟网络失败、服务错误及持续不响应直至接口配置的有限超时；也覆盖曾读取成功后重新读取失败。

预期：错误/超时后loading结束，卡片框架和获授权入口保留，旧数字及占位0均不显示；持续显示日文失败提示和「再読み込み」，超时有日文说明，无SQL/堆栈暴露。公共通知至多一次，页面不追加重复弹窗；页面不无限等待、不自动循环重试。超时值按实现记录核验，不假定浏览器无上限等待。

### VAL-10 重试与请求隔离

操作：失败后连续点击重试；分别令新请求成功、失败和超时；请求中跳往其他页面再返回；令旧请求在新请求成功或加载期间迟到返回。

预期：单次用户重试仅发一个GET，在途禁止重复重试，结束后立即解除限制；失败/超时仍可再试，成功替换六块结果。离开不受统计请求阻塞，返回重新读取；旧成功/失败及finally均不覆盖当前结果、错误或loading。所有重试均只读，不产生业务记录。

## 3. 回归检查清单

- 看板数字不随任何「保存看板」类操作变化——本页无此操作，数字只随业务模块记录变化。
- 已删除／已作废的记录不出现在任何卡片口径中。
- 「今日」「逾期」跨日时区边界按日本业务日判断。
- 订单一览三列（租赁／销售／替代）均按同一口径统计；进行中 = 未发完（已发完不计入），无「需核对」。
- 两处在制品、待质检、绑定部件数量及对应跳转筛选统一排除已报废产品，保留原业务事实。
- 待返送无「不再关注」类人工标记入口。
- 今日作业只有工作组维度，无人员维度。
- loading、真实0、失败明确区分；有限超时能结束等待，重试单在途，离开及迟到响应隔离。

## 4. Definition of Done

- §1 全部统计口径用例通过；§2 跳转及加载/失败/重试用例（VAL-07～10）通过。
- 在其他模块登记业务后，首页下次展示即反映，无需任何同步操作。
- 回归检查清单全部通过。
