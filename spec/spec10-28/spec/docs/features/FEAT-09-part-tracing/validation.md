本文件验证部件追溯页的筛选、履历、导出与删除规则。部件个体的建档用例见 FEAT-05／06，资料版本规则见 FEAT-02，绑定用例见 FEAT-06 部件组装。

## 1. 部件追溯

### VAL-01 筛选与导出

分别按部件类型、编号关键词片段、部件资料、当前归属（未绑定／使用中）筛选；组合使用；点击导出。

预期：列表按条件收窄；重置恢复全部；导出按当前筛选结果生成 Excel 文件，内容与页面列一致（导出功能 demo 尚未实现，属待实施项）。

### VAL-02 详情履历

打开一个有安装、更换、资料更正历史的部件详情。

预期：基础信息五字段正确；履历倒序含首次登记、安装／解除、被更换、资料更正（从哪份内容到哪份内容）与操作人；无产品跳转链接。

### VAL-02b 撤销安装履历

打开一个有撤销安装记录的部件详情。

预期：履历含撤销安装条目，显示撤销时间与操作人（如有记录）。

### VAL-02c 删除取消

对未绑定部件执行删除，在二次确认弹窗点击取消。

预期：弹窗关闭，数据无变化，部件仍在列表中。

### VAL-03 删除阻断

对当前已绑定产品的衣体（例：PTG26001）执行删除部件。

预期：阻断弹窗提示「该部件当前已绑定产品 PTG26001，请先解除绑定」；数据无变化。

### VAL-04 删除执行、历史保留与同编号重建

旧传感器档案 A（编号 S001）已有在产品甲的安装、拆除、资料更正及固件变更记录，当前无有效绑定。确认删除 A，再以 S001 建立档案 B 并安装到产品乙。

预期：二次确认说明当前不可用、原历史保留、编号可重建但历史不继承；删除后 A 从有效列表、选择结果和业务操作范围消失，不能再安装、资料更正或固件升级，记录删除时间及操作人。通过仍存在的甲产品或其他关联业务历史查看时，继续显示 A 当时的编号、采用资料、安装／拆除／更正／固件事件内容，能理解发生过什么，不能只剩孤立 ID 或删除日志；数据验证确认 A 的身份与历史数据未被清除。B 与 A 身份不同，无 A 的固件、绑定及资料更正记录；甲的历史不按 S001 改指 B，乙只产生 B 的新历史。曾经安装及固件历史不阻断删除。不要求新增已删除档案查询页、历史检索、恢复或导航入口。

### VAL-05 正常换衣体不产生可删除旧档案

对 PTG26001 正常登记更换衣体，再检查系统衣体及绑定，并尝试从部件追溯删除该衣体。

预期：产品和衣体身份、制造编号、绑定均保持；没有新衣体或无绑定的“换下旧衣体”档案；删除仍因当前有效绑定阻断。线下实物报废不登记为产品报废或在线旧衣体报废。

### VAL-06 绑错产品的纠正

同一真实部件 S001 错绑产品甲，结束当前绑定后安装到产品乙，不删除正确档案。

预期：始终为同一部件身份；甲、乙相关操作历史都保留，当前归属为乙。无需通过删除重建纠正绑定。

### VAL-07 资料错误与误建档分别处理

编号正确但资料错误时通过既有机制更正；另对编号录错的档案先尝试直接删除，再解除其当前绑定并删除，按需重新登记。

预期：资料错误保留同一身份及更正记录，不要求删除重建；误建档存在当前绑定时阻断，解除后可删并按 VAL-04 保留原历史；不增加恢复、回收站或档案启停功能。

## 2. 回归检查清单

- 原档案删除不可再用；旧历史可读且不指向同编号新档案；无因固件或曾绑定新增的阻断。

- 部件追溯编号与归属是否仍是纯文本（不应出现跳转链接）？
- 是否出现删除后的撤销／回收站入口（不应有）？
- 删除阻断是否只检查当前绑定（历史绑定不应阻断）？
- 衣体常态删除是否被正确引导去解除绑定（而不是允许直接删）？

## 3. Definition of Done

- 可按类型／编号／资料／归属筛选并导出 Excel；
- 详情履历完整倒序、无跳转链接；
- 删除只按当前有效绑定阻断，当前档案退出范围、原身份与可读历史保留、编号复用不混淆身份；
- VAL-01 ～ VAL-07（含 VAL-02b／02c）全部通过；回归检查清单无命中。

- 本次关联验收门槛：修改和新增用例须取得实际验证证据后才可判定通过；不得沿用旧级联删除、新旧衣体编号对照、订单级保障确认书的预期。
