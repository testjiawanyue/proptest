## C04联验重点

- 同一产品多条受付：前回実績取建立最近的一条并显示其批次日期及全部当前类型；最新无类型也不回退。卡片独立扫描期间内有效事实并按产品去重。
- A先建立、批次9月20日；B后建立、追加9月1日旧批次：前回実績选B展示9月1日，不能改用B成立日期作为统计日期。
- 日本业务日期边界：对象月9月，7月1日及9月30日纳入，6月30日及10月1日排除。无基准月登记年目不使产品自动取得生命周期候选资格。
- 9月20日向9月1日旧批次追加，不满足9月10日发行案内。还须验证案内实际生成在受付之后时不能追溯认领；不得套用前回実績最近一条算法。
- 仅有C04消费结果不阻断合法删除。删除最近一条后，前回实绩、期间去重、案内匹配分别按各自规则重算；案内无剩余匹配时恢复未受付／按原发行日判断超期，不向其他案内借用受付。
