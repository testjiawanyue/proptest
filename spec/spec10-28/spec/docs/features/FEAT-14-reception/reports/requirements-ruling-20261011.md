## 2. 已修正的关联冲突

1. FEAT-14开头流程图曾把完成批次画在履历／后续模块之前，容易误作发布门槛；改为小番号建立后即可查询，批次记录表另按生成门槛。
2. FEAT-16“保存受付后即出现”指代不明；明确建号时即可查询，原Tab／筛选继续生效，查看不建立作业记录。
3. FEAT-14／15重复规则只规定按基准显示年度，未覆盖无基准；同步年目与目标年月分离。
4. FEAT-14无基准生命周期整区“—”会隐藏真实已登记年目；改为基准及经过时长未知，历史年目仍展示。FEAT-15共享说明同步。
5. 年度禁选解释曾写“那一年已经做完”；改为“已经登记”，避免误认为实际点检完成。
6. 既有报告中的无基准待裁决结论保留为历史记录，但增加本次裁决导航，不再作为当前未决规则。
