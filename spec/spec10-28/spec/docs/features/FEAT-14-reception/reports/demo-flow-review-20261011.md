## 4. 待裁决的问题与修订建议

仅以下缺口会改变业务结果；已有明确正式规则的demo偏差不重新请用户裁决。

1. **无基准产品的定期点检**：建议先明确可完成的路径。是先补齐合法生命周期基准再选择年度，还是允许登记年目但年月暂缺？对应§6.4、VAL-10/12；未选择方案前不生成日期或豁免校验。
2. **空批次及未完成向导**：是否允许零受付批次完成？未确认来件的空批次从履历重开，应继续向导还是进入工作台补信息？对应§4.7～4.9、4.14、VAL-02/16/17。demo当前两者均可绕过来件确认。
3. **切换类型后的字段命运**：撤掉定期／切为报废时，原年度、作业、NG应清空、仅隐藏保留，还是恢复类型后作为草稿提示？需与§6.4非定期年度为空及下游消费一致；不能只定义视觉隐藏。

首轮报告的实际受付日期更正／旧批次追加日期问题仍保留为C04边界缺口；本轮没有日期更正入口证据，不为其设计流程。建议报废保留备注入口、保护人工计划、按整数拒绝小数等是恢复已有正式规则，不属于新增业务裁决。
