# FEAT-14 受付工作台 Validation

> **需求定版（2026-10-11）**：本轮FEAT-14受付及FEAT-15～17关联验收要求已经用户确认定版；本次确认是需求认可，不是用例执行通过或运行验收。本轮不进入开发；原有明确标注待定稿的报告／打印模板不在本次定版范围内。

**状态：Current Truth**

## 1. 受付工作台

### VAL-01 初始页入口与新建大番号

操作：进入「受付工作台」，核对标题、说明和两个入口卡片；点击「新しい受付を開始」。

预期：页面显示「受付を開始」及来件到达后的操作说明；点击新建后立即建立一个大番号和包裹 1，并进入新建批次前置流程。未要求先填写客户、地址或产品。

### VAL-02 既存受付入口

操作：在初始页点击「既存の受付を開く」。

预期：进入受付履歴，可从已建立的大番号继续追加产品或补充输入；初始页不建立新的受付记录。

### VAL-03 前置流程第 1 步面单拍照

操作：新建大番号后进入第 1 步，先不拍照点击「面单完成，开始拆箱」；再返回并拍照、重新拍摄。

预期：0 张面单图片也可进入第 2 步；拍照后显示缩略图和「已保存到 Package 1」；重新拍摄后 Package 1 的面单图片更新。

### VAL-04 前置流程第 2 步识别第一台产品

操作：在第 2 步不输入製造番号，尝试点击「识别产品」；输入可识别产品并识别；再输入不存在产品。

预期：未输入时按钮不可用；识别成功后显示製造番号大字和当前下单方、当前納品先、订单番号、地址、联系人、电话；无当前订单关系时显示来件信息需人工确认，但不阻断进入第 3 步——允许进入「确认来件信息」，候选内容为空由员工自行填写；未找到产品时给出警告，不得进入下一步。

### VAL-05 前置流程第 3 步确认来件信息

操作：识别第一台产品后进入第 3 步，核对提示条和表单字段；清空公司名称或来件地址尝试确认；补齐后点击「确认并进入受付工作台」。

预期：提示说明本次来件来源信息可按面单或现场情况修改，且不回写客户或订单主数据；公司名称和来件地址缺失时不得确认；补齐后保存大番号来件信息（含納品先）和包裹 1 备注，建立第一条产品受付并取得小番号，进入工作台。第 3 步納品先由第一台产品当前订单关系带出候选值，保存为本大番号来件记录；工作台左侧参考中的納品先读取本大番号来件记录，未保存时回退第一台产品当前订单关系；编辑大番号弹窗提供納品先字段并可更正。

### VAL-06 工作台顶部与位置恢复

操作：进入工作台后核对顶部操作区；点击大番号信息按钮、包裹页签、「＋」页签和「受付履歴」；从履歴页切回。

预期：大番号按钮显示「大番号 N · 客户名/未确认客户」并打开编辑大番号弹窗；包裹页签可切换；「＋」打开新建包裹弹窗；进入履歴再切回时恢复原大番号、包裹和受付位置。

### VAL-07 左侧上下文面板

操作：选择有当前受付、有生命周期、有关联案内和有历史业务的产品，再选择无相关信息的产品。

预期：左侧按固定顺序显示製造番号、受付番号、本次来件、ライフサイクル、最新案内、最近业务和 CURRENT PACKAGE；无值按规定显示「—」或隐藏相应参考；不显示次回予定。ライフサイクル的「点検済み」取本台产品历史受付中已填写年度的集合（排除当前编辑中与已删除的受付记录），升序以「・」连接（如「点検済み：2年目・3年目」），无记录显示「点検済み：—」；最近业务默认展开最新 1 条，可打开全量历史。

### VAL-08 扫描并开始受付

操作：在工作台扫描面板输入可识别製造番号并点击「受付を開始」；再分别输入不存在产品、已确认报废产品、已确认回收产品。

预期：识别成功后建立新的单台受付并取得小番号，打开受付表单；扫描本身不建立记录，必须开始受付后才建立；不存在产品给出警告；已确认报废产品提示不能受付且不建立记录；已确认回收产品允许正常建立新受付，原受付记录不受影响。

### VAL-09 受付表单报废互斥

操作：在受付表单先选择定期点检、维修、租赁结束，再选择报废；随后取消报废并选择其他受付类型。

预期：报废与其他类型互斥。未人工选择计划时，报废默认报废，包含租赁结束默认PROP回收，其余定期点检／维修默认返回客户，与点击顺序无关。人工选择或清空计划后不自动覆盖；取消报废类型只清除自动带出的报废计划。切为报废清除年度、本次作业、受付NG及照片，切回不恢复；备注、客户确认和箱数保留。

### VAL-10 年度完成情况单值与置灰

操作：选择定期点检，查看 1～4年目选项；准备同一产品其他有效受付已登记某年度，再编辑当前受付。

预期：一次受付最多选择 1 个年度；有基准月时选项显示「N年目（YYYY 年 MM 月）」，无基准月时显示「N年目（目标年月不明）」且可选择；同一台产品在之前其他有效受付里已登记过的年度置灰不可选并显示完成日期（该年度已登记，不能重复登记，不代表作业完成）；当前正在编辑的受付自身不参与禁用——员工已选的年度仍可改回或改选，不被自己的选择锁死。

### VAL-11 异常/NG 与备注

操作：在非报废受付中添加异常/NG，使用快捷选项、编辑内容、拍摄 1 张照片、删除照片并重拍；添加受付备注，再编辑和删除。

预期：NG 卡片显示序号、照片或空相机图标、内容、编辑和删除确认；每项最多 1 张照片；备注显示内容、录入人和日期；客户确认为需要确认且备注为 0 条时显示红色提示。

### VAL-12 校验并推进未入力反路径

操作：建立受付后分别缺少受付类型、年度完成情况、本次作业、客户确认、处理计划、受付备注、临时装箱，点击「保存并扫描下一台」。

预期：按统一未入力规则阻止推进，已按§4.13A保存的字段不因校验失败撤销；对应区块显示「请选择或填写此项」；页面定位到第一个缺失区块；顶部消息列出缺失项名。报废时不检查年度完成情况、本次作业和异常/NG。

### VAL-13 校验并推进正路径

操作：完成一条非报废受付的必填输入，并添加临时装箱；再完成一条报废受付。

预期：点击「保存并扫描下一台」后，非报废受付通过未入力校验并回到扫描面板；报废受付在无需年度完成情况、本次作业和异常/NG的条件下通过校验并推进。该按钮不再保存字段，不完成作业、报告、返送、回收或报废。

### VAL-14 客户确认旗标

操作：将某单台受付设置为「需要向客户确认」并保存；再改为「不需要确认」。

预期：需要确认时该受付、所属包裹页签和受付履歴大番号确认列显示 ⚑；改为不需要确认后旗标消失，已填写的受付备注保留；页面不提供手工增删旗标入口。旗标只判断「有效且需要向客户确认」，不判断产品是否已回收或已报废——已回收/已报废的受付只要仍标记为需要确认，旗标照常显示，如需去掉须把该受付的「需要向客户确认」取消。

### VAL-15 多台与多包裹登记

操作：在同一大番号下登记多台产品，新增包裹后登记产品；删除一个空包裹后再新增包裹。

预期：每台实际来件取得新的小番号；小番号跨包裹连续，不因包裹变化重置；删除空包裹后其他包裹序号不重排；新增包裹取现有最大序号加 1。

### VAL-16 完成本批次受理反路径

操作：大番号下存在未入力受付时点击「完成本批次受理」并确认。

预期：按小番号逐项列出缺失，不执行本次按钮返回；已保存内容保留，留在当前页；不存在完成时间或状态写入。

### VAL-17 完成本批次受理正路径

操作：补齐本批次所有有效受付的未入力项后点击「完成本批次受理」，确认弹窗。

预期：确认提示结束本次录入并返回初始页，取消留在当前页；通过查漏并确认后返回初始页，不记录完成时间／状态，不改变已保存内容及下游事实。重新打开批次仍显示完成按钮，可继续修改或追加。

## 2. 工作台内弹窗

### VAL-18 编辑大番号弹窗

操作：点击顶部大番号信息按钮，修改公司名称、联系人姓名、来件邮编、电话、来件地址、来件地址补充和来件备注；追加、预览、删除大番号画像后取消弹窗。

预期：保存来件信息后只更正本大番号来件信息，不回写客户或订单主数据；大番号画像与包裹图片分开保存；已完成的图片追加或删除不会因取消弹窗撤销。

### VAL-19 新建/编辑包裹弹窗

操作：点击「＋」页签新建包裹，再从 CURRENT PACKAGE 点击编辑包裹，维护包裹备注和包裹图片。

预期：包裹名称自动生成并禁用显示；备注和图片保存到该包裹；可显示多张图片缩略图并删除。

### VAL-20 编辑临时装箱

操作：点击临时装箱输入框，分别输入 0、负数、小数、空值和 1 以上整数。

预期：仅 1 以上整数可保存；保存后表单显示「N 箱」并满足未入力检查。

### VAL-21 删除小番号反路径

操作：对已存在作业记录、已生成单台点检报告、已存在返送记录、已确认回收或已确认报废的受付点击产品行删除图标。

预期：删除阻断弹窗一次性列出全部原因，只能点击「知道了」关闭；受付记录、受付备注和正式 NG 均不删除。

### VAL-22 删除小番号正路径

操作：对无任何后续业务数据的受付点击删除图标并确认。

预期：二次确认文案说明受付记录、受付备注、正式 NG 将一并删除，小番号不再复用且不可恢复；确认后记录被删除，该小番号成为空号。

### VAL-23 产品全量业务历史

操作：点击左侧「すべての履歴を見る」。

预期：打开只读时间线，按倒序显示当前产品全部有效受付，包含当前受付；每条显示有值的工作组记录原始字段；无历史显示「暂无历史记录」。

## 3. 页面间完整闭环

### VAL-36 新建受付端到端闭环

```text
受付工作台初始页点击新建
→ 完成前置流程 4 步
→ 登记第一台产品受付
→ 保存并扫描下一台
→ 新增包裹并登记第二台产品
→ 补齐未入力
→ 完成本批次受理
→ 受付履歴查询该大番号
```

预期：全链路建立一个大番号、至少两个包裹和多条单台受付；每台受付取得年度内连续小番号；不记录批次完成状态或时间；受付履歴按大番号显示包裹、产品、未入力和确认旗标。

### VAL-37 补充登记闭环

```text
已有大番号
→ 从受付履歴切回工作台
→ 追加新的包裹或产品
→ 按操作保存追加受付内容
→ 返回受付履歴
```

预期：原批次受付日期保持不变，不记录完成状态或时间；新增产品取得新的小番号；后续点检、维修、报告和返送不因补充登记自动改变。

### VAL-40A 操作即保存与弹窗保存边界

依据：spec §4.13A既有规则（2026-09-22）；本次补齐用例，不补记历史通过。

操作：点选受付类型、年度、本次作业、客户确认和处理计划，不点击底部按钮即切换产品、包裹并返回；分别在NG、备注、临时装箱弹窗保存及取消；保留必填缺项点击底部按钮，再补齐后推进。

预期：选择及弹窗已保存内容保留，取消不写入本次弹窗未保存输入；底部校验失败不撤销已保存字段，成功只清空当前选中状态并回到扫描面板，原受付仍在。下一次点击扫描开始受付前不建立新的小番号。

## 4. 回归检查清单

- 是否出现选择类字段点击后未保存、或必须点底部「保存并扫描下一台」才保存字段的情况？
- 是否出现未点击「受付を開始」就建立单台受付的情况？
- 是否出现同一实际来件打开旧受付记录而不是取得新小番号的情况？
- 是否出现小番号按包裹重置、删除后复用或删除大番号后回退计数的情况？
- 是否出现删除包裹后其他包裹序号被重排的情况？
- 是否仍生成受付完成时间／状态，或把完成按钮当成下游放行门槛？
- 是否把产品处理计划当成实际回收或报废事实？
- 是否让大番号来件信息回写客户或订单主数据，或被主数据后续变化覆盖？
- 是否允许员工手工增删 ⚑ 旗标？
- 是否在包裹或大番号层显示字段缺失总数，而不是未入力台数？
- 是否恢复了已明确不做的结束本包裹、小番号作废、独立来件管理、左卡次回予定、受付记录关联通知、受付履歴产品行详情入口或产品处理计划「未决定」？
- 是否允许批次记录表阻断删除大番号，或删除大番号时遗漏清理批次记录表？
- 是否允许 NG 保存多张照片？

## 5. Definition of Done

- 受付工作台初始页、前置流程、工作台、工作台弹窗和受付履歴均符合 spec.md。
- 新建受付、多台多包裹登记、保存校验、完成本批次受理、履歴查询、批次记录表和三层删除均有验收记录。
- 编号规则、未入力规则、⚑旗标、年度口径、受付类型与处理计划联动均通过正反路径验证。
- 来件信息和处理计划的业务边界未被扩大，完成按钮不产生完成时间或状态。
- 删除行为符合三层删除条件和后果，且不会复用小番号或重排包裹序号。
- 批次记录表按版本保存生成时批次事实，历史查看不被当前资料改写。
- 明确不做项没有在页面、数据变化或验收用例中复活。

## 7. 2026-10-11 裁决新增验证要求（未执行）

### VAL-41 先建小番号、暂缺必填与跨页面读取

操作：首台仅识别产品，随后确认来件信息；在工作台另开始一台受付。两台均保留必填缺项，不点击底部按钮和完成批次，切换产品、包裹、返回初始页后重开；到履历及作业管理用能覆盖该记录的筛选查询。

预期：仅识别不建号，前置确认／后续开始受付时即建立小番号；缺项不撤销受付，不阻止已确认合法内容保存及上述导航。履历、作业管理可查询，底部校验不是可见门槛；不存在“登记通过后才进入正常待作业”的额外状态。默认筛选隐藏不匹配记录与未建记录须区分；查看本身不创建作业记录。

### VAL-42 持续修改与校验边界

操作：已填齐受付改为需要客户确认且无备注；不点击底部按钮即切换并返回。尝试临时装箱保存非法箱数；分别验证弹窗取消及保存失败。

预期：客户确认选择按操作保存，备注缺项随之出现，其他已保存内容保留；底部查漏不通过不回滚已保存选择。允许暂缺不豁免正整数、年度及互斥规则；非法箱数不能保存。取消不提交当前弹窗输入；保存失败明确提示，不能声称保存成功。本条不承诺离线或未确认输入恢复。

### VAL-43 无基准月的年度登记

操作：无基准月产品选择定期点检，先不选年度，再选择2年目并补齐其他适用必填项；点击下一台及完成批次。重开，查询履历与作业管理；同产品另一次受付检查年度禁选。
