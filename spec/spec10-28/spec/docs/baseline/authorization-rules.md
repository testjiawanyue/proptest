# PROP 权限与数据范围

本文件是 PROP 跨功能的正式权限规格。2026-09-30 将 AGENTS 中已确认规则迁入产品事实源，未新增或改变业务行为；各 feature 仍定义该页面的具体功能与共享接口消费范围。

## 授权规则

1. PROP 仅采用页面级授权，通过现有角色／菜单管理控制页面可见性和访问。获得页面权限后可使用该页面规定的全部业务功能，不另行分配新增、编辑、删除、启停等操作权限，不建立按钮权限矩阵。
2. 服务端必须校验对应页面访问权限，不能只隐藏菜单或按钮。沿用若依鉴权机制，不另建权限体系，不因 HTTP 方法或动作不同拆分操作授权。
3. 多个页面共用的查询／选择接口按实际消费页面的访问权限校验。拥有合法消费页面权限的用户无需同时拥有资料维护页面权限；只开放该页面所需的共享读取，不因此授予维护页面或其他写入接口权限。
4. PROP 业务数据在公司内共享，获授权用户访问同一业务数据范围，不按部门、个人或记录归属做权限过滤。若依系统管理模块既有操作权限及数据权限保持不变。
5. 页面授权不能替代字段约束、对象归属、状态限制、删除阻断、事务一致性等后端业务校验。业务对象归属校验不是部门或个人数据隔离。
6. DS 通用按钮权限和 DataScope 示例须遵循上述项目边界，不机械应用于 PROP。

## 验证要求

以下是验收要求，不代表本次文档迁移已执行运行验证：

- 普通角色仅获目标页面权限后，验证菜单、内部页面、直达刷新及该页面规定的功能；无权限角色访问页面与受保护接口应被拒绝。
- 仅获合法消费页面权限的角色可以读取所需共享资料，但不能因此访问资料维护页面或未获授权的维护接口。
- 获授权的不同部门／用户访问相同业务数据范围；后端对象归属及状态等业务校验仍生效。
- 修改 PROP 权限时，若依系统管理既有操作与数据权限不被扩大或取消。
