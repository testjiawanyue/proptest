# FEAT-17 返送 Validation

> **本次修订验证状态（2026-09-25）**：以下修改及新增场景为验收要求，均未执行；历史 demo 核对、旧测试结果不表示本次规则已验证。原型资产未更新，冲突表现以本次正文为准。

**状态：Current Truth**

依据 [spec.md](spec.md) 逐页验收。本轮为静态核对稿，尚未执行浏览器实测、自动测试或构建。用例按返送闭环编写，覆盖返送管理、返送详情、返送寄送抽屉（准备中／确认寄出／寄出后维护）与返送边界。

## 1. 返送管理

### VAL-01 列表内容与排序

操作：进入「返送管理」，核对行内容与排序。

预期：每行显示大番号（附受付日期、受付完了标记）、客户（附来件邮编地址）、返送状况（待返送 N 台／已返送 · 可返送 · 共 N 台／未生成报告标签）、返送面单（件数与最新返送编号）；受付日期最早的批次排最前。

### VAL-02 筛选

操作：分别使用大番号、客户名称、地址、受付日范围、返送状况（全部／有待返送／暂无待返送）筛选；重置。

预期：文本类为部分匹配；受付日按范围过滤；返送状况按待返送数量是否大于 0 分流；重置清空全部条件。

### VAL-03 待返送口径

操作：对同一大番号制造以下情形并核对「待返送」计数：计划返回客户且未返送的产品；计划返回客户但已进入准备中面单的产品；计划返回客户且已确认寄出的产品；计划为 PROP回收的产品。

预期：仅第一类计入待返送；准备中面单不影响待返送计数（不反映勾选过程）；已确认寄出、计划回收均不计入。

## 2. 返送详情

### VAL-04 产品表内容

操作：进入某大番号返送详情，核对产品表六列。

预期：产品（製造番号＋受付番号连写）；当前计划（返回客户／PROP回收／报废／未定）；点检作业——返回客户显示 完了／作業中（与作业管理同口径），报废已确认显示 廃棄済、未确认显示 —，回收已确认显示 回収済、未确认显示 —；报告书——未生成显示 未生成＋生成报告（处理计划已定时），已有显示 查看报告 vN＋再生成；展开维修报告显示存放路径或 —；实际处理结果显示 报废済／回收済／已返送·编号／面单准备中·编号／未返送。

### VAL-05 就地生成报告

操作：对处理计划已定的产品点击「生成报告」，确认生成；再次点击「再生成」。

预期：弹窗与作业管理一生成机制一致；确认后产生新不可变版本并弹出预览（可下载／打印）；再生成版本号递增；处理计划为空的产品无生成入口；生成报告不产生返送事实。

### VAL-06 面单表与入口

操作：核对返送面单卡；点击「生成面单」「继续返送」「查看」「打印」。

预期：面单按创建时间倒序列出；准备中显示「继续返送」，已发出显示「查看」「打印」；点击「生成面单」只打开新建态抽屉，此时不建立面单记录、不取得返送编号；首次保存、生成文件或确认寄出时才建立准备中面单并取得返送编号。

## 3. 返送寄送抽屉（准备中）

### VAL-07 勾选与不可选原因

操作：新建面单，核对产品勾选表；尝试勾选报废済、回收済、已在其他面单（准备中／已确认）的产品。

预期：全部有效受付产品按小番号列出（#／製造番号／受付番号／当前计划／状态）；报废済、回收済、已在其他面单的产品不可勾选，状态标签说明原因（附日期或面单号）；计划为 PROP回收／报废但未正式执行的产品可勾选。

### VAL-08 混装提示

操作：勾选包含计划为「PROP回收／报废」的产品。

预期：顶部提示本次面单包含 N 台当前计划为「留存／报废」的产品，说明面单只是寄送记录、允许混装，请确认实物装运无误。

### VAL-09 保存与校验

操作：不勾选任何产品点击保存；来源大番号无来件地址时点击保存；正常勾选后点击保存。

预期：无产品时保存被阻断并提示（如不再寄出请使用删除）；无来件地址被阻断并提示；正常保存后面单处于准备中，不登记寄出事实。收货单位与地址卡全程只读，无修改入口。

### VAL-10 打印不登记寄出

操作：在已保存的准备中面单中选择快递公司，点击「生成面单（2 张）」；点击「打印納品書」。另在新建抽屉（尚未保存）中勾选产品后直接点击「生成面单（1 张）」。

预期：已保存面单点击「生成面单（2 张）」产生一个面单新版本（2 张为复印份数、共用同一版本，提示「同一版本复印」）并弹出预览，「打印納品書」生成一个納品書新版本；均不登记寄出、不改变寄送状态。新建抽屉直接生成面单时，会先建立准备中寄送并保存所选产品（此后这些产品不能加入其他面单），再生成文件。

### VAL-11 删除准备中面单

操作：对未生成过文件的准备中面单点击「删除」并确认；对已生成多版面单、納品書的准备中面单先取消删除，再确认删除；另核对该准备所属全部文件／邮件版本（如有）及其他业务记录。

预期：二次确认「删除后不可恢复」；取消时准备、清单与文件均不变。确认后无文件、有文件的准备均可删除，准备及所属清单关联、全部文件与邮件版本不保留业务历史；产品解除该准备占用并按原资格恢复可勾选。产品档案、受付、作业、报告、其他寄送及正式履约不受影响。

## 4. 确认寄出

### VAL-12 确认弹窗校验

操作：未选快递公司时打开「补充运单号并确认寄出」；选择快递公司后再次打开；输入重复运单号。

预期：未选快递公司时提示先选择、不得确认；弹窗说明「确认表示本次 N 台产品已经实际寄出。确认后产品清单与订单关联冻结；快递公司、寄送日期与运单号仍可修改」；含计划非返送产品时提示计划保持不变；运单号重复时提示合并。

### VAL-13 确认寄出结果

操作：补充运单号后点击「确认寄出并生成邮件」。

预期：登记正式返送事实（不可逆），弹窗关闭；抽屉切换为寄送详情态——产品清单只读附「已确认寄出」，出现已生成文件卡与运单号维护卡，邮件正文在已生成文件卡查看与复制；返送详情中该批产品实际处理结果变为「已返送 · 编号」。

### VAL-14 批次已返送计数

操作：同一大番号分两批寄出不同产品（两张已确认面单），核对批次「已返送」计数；再尝试把已寄出产品加入新面单。

预期：已返送数为两批不同受付产品的合计；已寄出产品不可再勾选（已返送永久退出候选），不存在同一产品被重复寄送的情形。

## 5. 寄出后维护

### VAL-15 属性更正

操作：确认寄出后修改快递公司、实际寄送日期、箱数；核对收货单位与地址卡。

预期：修改即保存并记最后修改人／时间；产品清单不变；既有邮件版本保持不变（不自动更新），点击「生成邮件正文」后按当前寄送信息产生新版本（版本号递增，v1 不被覆盖）；收货单位与地址只读，确认后同样无修改入口。

### VAL-16 运单号维护与邮件

操作：确认寄出弹窗中补充两个运单号并确认寄出；在运单号维护卡追加、修改、删除单号后「保存单号」；点击「生成邮件正文」两次，对已生成的邮件版本点击「查看」并复制正文。

预期：确认弹窗补充的运单号与运单号维护卡显示一致（同一份数据）；保存后运单号更新；关闭并重新打开抽屉后，多个运单号仍按多个独立行显示；每次「生成邮件正文」产生一个新版本并打开查看弹窗，历史版本不覆盖；查看弹窗显示该版本生成时间与正文全文，可复制；邮件列表按版本逐行显示，无「按当前内容现算后直接复制」的旁路按钮。

### VAL-17 已生成文件继续打印

操作：确认寄出后对历史面单、納品書点击「继续打印」。

预期：生成该类型新版本文件并弹出预览；历史版本保留可继续打印。

### VAL-18 不可撤回

操作：查看已确认寄出面单的抽屉底部。

预期：无撤回／作废入口；仅有「关闭并返回列表」。

### VAL-18b 正式返送的删除保护

正式确认寄出后检查界面，再直接调用删除请求。

预期：无删除入口；服务端拒绝删除，返送记录、清单、文件及正式返送事实均保持。不以已打印文件阻断准备删除，不允许接口绕过正式寄出限制。

## 6. 边界回归

- 准备有文件仍可删除，取消无变化，所属关联与全部版本移除；正式寄出后的删除在界面及服务端均被禁止。

### VAL-E1 返送不影响订单

操作：对来自某订单的产品完成一次返送确认，核对订单管理与产品详情。

预期：订单履约数量与订单关系不因返送改变；产品详情的返送历史新增一条已确认记录。

### VAL-E2 已返送产品永久退出候选

操作：对已确认寄出的产品再次新建面单，尝试勾选。

预期：该产品不可勾选，状态显示「已返送 · 编号」；不存在再次返送。

### VAL-E3 客户再次寄回走新受付

操作：已返送产品再次被客户寄回 PROP。

预期：在受付工作台建立新的受付记录（新一轮点检），不能用原受付的重复返送代替；原返送历史保留。

## 7. 回归检查清单

- 打印与寄出始终分离：任何文件生成／打印不登记寄出事实。
- 确认寄出只冻结产品清单；快递公司、日期、箱数、运单号确认后可更正；返送地址始终只读、随大番号来件地址。
- 待返送只统计计划返回客户且未实际返送；准备中面单不影响计数。
- 快递公司任一修改路径（抽屉选择／批量打印出单）后，面单印刷公司与系统记录一致。
- 报告生成与返送事实互不影响。
- 已确认寄出无撤回、无作废、无产品清单编辑。
