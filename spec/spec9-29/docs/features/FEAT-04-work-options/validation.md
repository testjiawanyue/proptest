# FEAT-04 作业选项 Validation

## 1. 作业 NG 描述

### VAL-01 三组字典范围

操作：查看作业 NG 描述的工作组。

预期：仅有縫製／センサ／組立三组；展開修理／クリーニング没有常用 NG 清单。

### VAL-02 新增／停用／启用

操作：在一个工作组新增一条作业 NG 描述，再依次停用、启用。

预期：该描述按操作更正状态，供 FEAT-16 作业管理读取使用。

### VAL-02a 空值与重名校验

操作：新增时依次提交空值、仅含首尾空白的值、与同类别同工作组已有值仅英文字母大小写或首尾空白不同的值、包含不同中间空格的值；再提交其他类别、其他工作组的同名值，并分别对已有启用项和已有停用项提交重复值。对受付 NG 快捷选项按全局范围执行同组检查。

预期：保存前去除首尾空白，处理后为空不可保存；作业 NG／处置在同类别同工作组内、受付 NG 快捷选项在该类别全局范围内将「 Test 」与「test」视为重复；启用项重名提示「该值已存在」，停用项重名提示「该值已存在且已停用，请使用现有启用操作」，均不重复建立或自动启用；「A B」与「AB」不自动视为相同；不同类别或不同工作组允许同名；显示保留去除首尾空白后的原输入大小写。并发提交同一归一值时最多建立一条记录。

### VAL-02b 停用不回写历史快照

操作：停用一条作业 NG 描述，再查看已登记该描述的历史作业记录。

预期：二次确认提示「停用后不再出现在新建选择中；已登记的历史记录保存的是文本快照，继续显示原值」；历史记录继续显示原值。

### VAL-02c 清单列与类别菜单

操作：查看左侧类别菜单与选项清单列。

预期：类别菜单含作业处置内容、作业 NG 描述、受付 NG 快捷选项三类；清单列显示选项值、来源（管理员／现场录入）、状态、登记时间、操作（停用／启用）。

### VAL-03 现场输入不回写

操作：在 FEAT-16 作业管理现场输入一个不在常用清单中的 NG 内容。

预期：新值只保存到该台作业记录，不进入该组常用 NG 清单。

## 2. 作业处置内容

### VAL-04 三组字典范围

操作：查看作业处置内容的工作组。

预期：仅有縫製／センサ／組立三组；展開修理／クリーニング没有常用处置清单。

### VAL-05 新增／停用／启用

操作：在一个工作组新增一条作业处置内容，再依次停用、启用。

预期：该内容按操作更正状态，供 FEAT-16 作业管理读取使用。

### VAL-06 现场输入不回写

操作：在 FEAT-16 作业管理现场输入一个不在常用清单中的处置内容。

预期：新值只保存到该台作业记录，不进入该组常用处置清单。

## 3. 受付 NG 快捷选项

### VAL-07 全局清单不分工作组

操作：切换到受付 NG 快捷选项类别。

预期：不显示工作组页签；清单为全局选项；支持新增／停用／启用。

### VAL-08 受付登记点击填充

操作：在 FEAT-14 受付工作台「④ 异常 / NG」登记弹窗点击一个启用的快捷选项胶囊。

预期：选项内容填入 NG 内容输入框，填入后允许继续编辑。

### VAL-09 停用不回写历史快照

操作：停用一条受付 NG 快捷选项，再查看已登记该内容的受付 NG；并打开受付登记弹窗。

预期：已登记的受付 NG 继续显示原值；停用项不再出现在登记弹窗的快捷选项胶囊中；启用后恢复显示。

## 4. 页面间完整闭环

### VAL-10 清单维护与现场使用

操作：在作业选项维护一条作业 NG 描述和一条作业处置内容，再到 FEAT-16 作业管理对应工作组选择。

预期：作业管理读取清单使用；作业现场不回写清单。

### VAL-11 受付快捷选项维护与登记

操作：在作业选项新增一条受付 NG 快捷选项，再到 FEAT-14 受付工作台「④ 异常 / NG」登记弹窗点击该选项完成登记。

预期：登记弹窗出现该快捷选项胶囊，点击填入内容并允许编辑；登记保存文本快照，之后字典停用不回写。

## 5. 回归检查

- 展開修理／クリーニング是否出现处置或 NG 常用清单（不应出现）？
- 现场输入的新值是否自动进入常用清单（不应进入）？
- 受付 NG 快捷选项是否按工作组分组（应为全局清单）？

## 6. Definition of Done

- VAL-01 ～ VAL-11（含 VAL-02a～02c）全部通过；
- 回归检查无命中。
