# FEAT-02 部件资料 Validation

## 1. 部件资料

### VAL-19 新建

分别新建合法的部件资料：前缀留空；前缀使用 `AQ2`；前缀使用中文、符号和大小写混合值。另输入一个超过 32 个 Unicode 码点的前缀并保存。

预期：空前缀可保存且列表显示 `—`；数字、中文、符号和大小写混合前缀不因字符类别被拒绝，保存与回读值不转换大小写或删除其中字符；超长前缀被拒绝且弹窗保留输入。

### VAL-20 规格必填

分别新建四类部件资料，均不填规格保存。

预期：四类部件不填规格均被拦截提示填写规格。

### VAL-21 编辑与版本

编辑已有资料：先只修改名称保存；再只修改规格保存；随后只修改厂商；将已有前缀清空后保存；再从空前缀改为包含数字、中文或符号的非空前缀并保存。

预期：每次保存均产生一份包含名称、规格、厂商和可空编号前缀完整内容的新版本；清空前缀的新版本为空，上一版本仍保留原前缀；从空改为非空时其他资料字段仍完整保存。所有旧版本完整保留且不被覆盖，当前页面不增加历史版本查看入口；已建档个体采用的资料版本不因此改变。另对资料选择错误的个体通过既有入口更正，核验同一身份与更正前后版本均保留；该个体按规则删除并以同编号新建后，原更正历史仍可读但不归入新身份。个体更正与删除重建部分为 2026-09-25 验收要求，未执行。

### VAL-22 停用影响

停用某气囊资料后：部件组装顶部默认资料下拉、新建个体时选择该资料。

预期：停用资料不再可选；已绑定该资料的部件与产品不受影响；可重新启用；停用和重新启用均不产生新的部件资料版本，最新资料版本保持不变。

## 2. 页面间完整闭环

VAL-19 ～ VAL-22 覆盖部件资料新建、编辑与版本保留、停用影响和重新启用。

## 3. 回归检查

- 部件资料停用是否影响了已建档个体（不应影响）？
- 规格文本是否被解析出颜色等结构化含义并用于拦截或推导（不应解析）？
- 前缀中的数字、中文、符号或大小写是否被自动删除、转换或拒绝（不应）？

## 4. Definition of Done

- 部件资料可新建、编辑（每次编辑保存完整新版本）、停用／启用；
- VAL-19 ～ VAL-22 全部通过；回归检查清单无命中。
