# FEAT-07 质检工作台 Validation

> 本文件是质检模块的完整业务验收标准。依据 spec.md 与业务理解编写，覆盖 demo 已实施与未实施部分；demo 未实施部分在 spec 对应章节已标注「目标稿（待转正）」。

## 1. 质检工作台

### VAL-01 默认加载全部待质检产品

打开质检工作台，不执行任何筛选。

预期：右侧清单显示当前全部待质检产品（满足最低构成且未通过）；清单标题显示「待质检清单（N 件）」；已质检通过或仍缺部件的产品不在清单中。

### VAL-02 范围筛选

在筛选区选择「連続入力」，前缀 PTG，开始 001，结束 005，点击【筛选】。

预期：右侧清单只显示製造番号 PTG26001～PTG26005 范围内的待质检产品；清单标题显示「筛选结果（N 件）」；范围外或已质检通过的产品不显示。

### VAL-03 单件筛选命中

在筛选区选择「番号入力」，输入完整製造番号（如 PTG26003），回车。

预期：右侧清单只显示该件（若满足质检条件且未通过）；清单标题显示「筛选结果（1 件）」。

### VAL-04 单件筛选未命中

输入不存在的製造番号（如 PTG99999），回车。

预期：提示「未找到该製造番号」；右侧清单不变化。

### VAL-05 单件筛选不满足最低构成

输入一个已建立但缺少气囊／传感器／或充气发生器位置 1（无论位置 2 是否安装）的製造番号，回车。发生器位置 1 有安装即满足构成；仅位置 2 有安装、位置 1 空缺时不满足构成。

预期：提示「不满足质检最低构成，无法登记」；右侧清单不显示该产品。

### VAL-06 单件筛选已质检通过

输入一个已质检通过的製造番号，回车。

预期：提示「已质检通过」；右侧清单不显示该产品。

### VAL-07 重置筛选

执行范围或单件筛选后，点击筛选卡标题行右侧「重置筛选」。

预期：清空筛选条件，右侧恢复默认全部待质检清单。

### VAL-08 勾选与确认质检通过

在清单中勾选 2 台待质检产品，点击底部「确认质检通过（2 台）」。

预期：弹出最终确认框，列出 2 台製造番号，提示「确认后产品将标记为质检通过，无法撤回」；点击「确认质检通过」后，2 台产品从待质检清单消失；产品列表中该 2 台生产阶段变为「已完成质检」；底部提示「成功 2 台，失败 0 台」。

### VAL-09 确认质检取消

勾选 1 台产品，点击「确认质检通过」，在确认框中点击「取消」。

预期：确认框关闭，清单与勾选状态不变，不产生质检事实。

### VAL-10 确认质检部分失败

勾选多台产品，其中一台在确认前被其他操作移除部件导致不满足构成（或通过测试构造失败场景），执行确认。

预期：成功的产品建立质检事实并消失；失败的产品保留在清单中，状态列显示红色失败原因；底部提示「成功 N 台，失败 M 台」。

### VAL-11 筛选与勾选联动

先范围筛选出 3 台，勾选其中 2 台；再执行单件筛选定位另一台。

预期：单件筛选后右侧清单只显示该台；原勾选状态保留但不在当前清单中的产品不参与本次确认。

## 2. 跨页面闭环

### VAL-12 衣体入库 → 组装 → 质检 → 产品列表

衣体入库建立新产品 → 在部件组装页录入气囊、传感器、发生器位置 1 → 打开质检工作台 → 勾选确认质检通过 → 打开产品列表。

预期：质检工作台清单中出现该产品；确认后产品列表中该产品生产阶段为「已完成质检」，首次质检通过日显示当日；产品详情中可见质检通过事实。

### VAL-13 质检通过不可撤回

对已质检通过的产品，在产品详情、产品列表、质检工作台寻找撤回或取消质检入口。

预期：系统不提供任何撤回质检的入口；质检通过事实保留在产品档案中。

## 3. 回归检查清单

- 是否存在「质检不通过」或「返工登记」的入口？（不应存在）
- 是否存在「打印编号清单」按钮？（不应存在）
- 不满足最低构成的产品是否出现在待质检清单中？（不应出现）
- 已质检通过的产品是否仍出现在待质检清单中？（不应出现）
- 发生器位置 2 为空但位置 1 已安装的产品，是否被正确视为满足最低构成？
- 筛选条件是否影响质检事实本身？（不应影响，只影响清单显示）

## 4. Definition of Done

- 质检工作台默认加载全部待质检产品；
- 范围筛选与单件筛选行为符合 spec 4.5；
- 确认质检通过有最终确认框，逐台建立事实，失败行保留并显示原因；
- 质检通过事实包含确认人、确认时间；
- 质检通过后产品生产阶段变为「已完成质检」；
- 系统不提供质检撤回入口；
- 无「打印编号清单」功能；
- 与 FEAT-05～08、FEAT-08 产品管理的生产阶段口径一致。
