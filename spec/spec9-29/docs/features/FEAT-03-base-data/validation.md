# FEAT-03 基础数据 Validation

## 1. 对外产品名称

### VAL-01 启用项供订单选择

操作：打开 FEAT-10 订单表单的对外产品名称选择。

预期：可从启用的对外产品名称中选择。

### VAL-02 产品名称不决定实物规格

操作：选择一个对外产品名称并填写订单。

预期：该名称不决定实物颜色或规格。

### VAL-02a 新增字典项

操作：在对外产品名称类别下点击「新增」，输入一个新值并保存。

预期：行内输入区保存后，该项以启用状态出现在清单中，立即可供 FEAT-10 订单表单选择。

### VAL-02b 空值与重名校验

操作：依次尝试保存空值、仅含首尾空白的值、与同类型已有值仅英文字母大小写或首尾空白不同的值、包含不同中间空格的值，以及其他类型下的同名值；再分别对已有启用项和已有停用项提交重复值。

预期：保存前去除首尾空白，处理后为空不可保存；同一类型内「 Test 」与「test」视为重复，启用项重名提示「该值已存在」，停用项重名提示「该值已存在且已停用，请使用现有启用操作」，均不重复建立或自动启用；「A B」与「AB」不自动视为相同；不同类型允许同名；显示保留去除首尾空白后的原输入大小写。并发提交同一归一值时最多建立一条记录。

### VAL-02c 停用与历史引用不回写

操作：停用一条已被引用的对外产品名称，再查看引用它的历史订单。

预期：二次确认提示「停用后不再出现在新建选择中；已引用的历史记录继续显示原值」；确认后该项不再出现在新建选择的下拉中，历史订单继续显示原值；启用后恢复可选。

### VAL-02d 字典范围

操作：查看左侧类型菜单。

预期：菜单只有对外产品名称、传感器固件版本两类；不存在其他字典类别。

## 2. 传感器固件版本

### VAL-03 启用项供作业选择

操作：打开 FEAT-16 作业管理中センサ部品情報的バージョンNo下拉。

预期：选项来自基础设置中启用的传感器固件版本。

## 3. 页面间完整闭环

- 对外产品名称由基础数据提供启用项，FEAT-10 订单管理负责选择和订单内一致性。
- 传感器固件版本由基础数据提供启用项，FEAT-16 作业管理负责选择和登记升级事实。

## 4. 回归检查

- 对外产品名称是否被用于决定实物颜色或规格（不应决定）？
- 基础数据页面是否出现两类以外的字典类别，如颜色、快递公司（不应出现）？
- 作业管理是否出现基础设置中未启用的传感器固件版本（不应出现）？

## 5. Definition of Done

- VAL-01 ～ VAL-03（含 VAL-02a～02d）全部通过；
- 回归检查无命中；
- 新增、停用、启用、被引用项处理规则与 spec §4.4～§4.5 一致。
