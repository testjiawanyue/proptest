# FEAT-19 订单批量打印 Validation

依据 [spec.md](spec.md) 验收。本轮为静态核对稿，尚未执行浏览器实测、自动测试或构建。

## 1. 订单批量打印面单

### VAL-15 页面结构、空态与数据范围（spec 4.1～4.4）

从订单列表进入「批量打印面单」，分别准备无订单寄送、准备中寄送、已寄出寄送、已删除寄送。

预期：标题为「批量打印面单」，返回到订单列表；快递公司默认 ヤマト運輸。表格只列订单来源准备中寄送；已寄出、已删除和返送寄送不出现。无数据时显示「当前没有准备中的订单寄送」。

### VAL-16 表格列与产品摘要（spec 4.4）

准备多笔订单寄送，包含长订单号、长收货单位、长地址、多台产品；核对每列展示。

预期：列为勾选、来源单号／寄送记录号、收货单位、产品摘要、台数、收件地址、面单张数、操作。产品摘要直接显示本次寄送制造编号列表，顿号连接，长内容省略并可查看完整内容；不按订单行名称和颜色聚合。收件地址列第一行显示邮编 〒XXX-XXXX，第二行显示地址。

### VAL-17 勾选、张数与汇总（spec 4.4～4.6）

勾选一笔、多笔和取消勾选；分别设置面单张数为 1、多个、空值、超过范围值。

预期：底部显示已选寄送笔数、汇总产品台数和预计打印面单张数；产品台数不随面单张数倍增。未勾选时按钮不可用；张数限制为 1–99，空值按 1 处理。

### VAL-18 批量打印动作（spec 4.5～4.7、5.1）

选择多笔寄送并设置不同面单张数，执行「批量打印面单（共 N 张）」；回到各笔抽屉查看已生成文件和订单履约数。

预期：提示「已生成 N 张［快递公司］面单（打印不登记寄出）」；每笔按设置张数生成面单，面单使用顶部所选快递公司，且该笔寄送的快递公司被改写为该公司（准备中未选公司的寄送随出单补齐）；不登记寄出、不改变准备状态、不建立产品与订单关系、不建立打印批次台账。正式模板转正时复核模板选择是否如期生效。

### VAL-19 修改工作单后刷新（spec 4.2、4.5）

从批量打印页点击「修改工作单」打开寄送抽屉，增删产品、修改收货相关以外的物流资料，关闭抽屉。

预期：回到批量打印页后该行产品摘要、台数、相关展示使用最新准备内容；勾选与张数行为仍正常。修改工作单不登记寄出。

### VAL-20 快递公司选择边界（spec 4.4～4.6）

勾选若干行后切换快递公司，再执行批量打印。

预期：切换快递公司不清空勾选；汇总栏和按钮提示使用新快递公司。顶部选择即本次面单模板，不筛选准备中寄送；点击打印出单时才把被打印寄送的快递公司改写为该公司，仅切换不改动任何寄送记录。

## 2. 页面间完整闭环

### VAL-22 批量打印 → 修改工作单 → 确认寄出（spec 4～5）

```text
订单列表进入批量打印
→ 勾选准备中寄送并批量生成面单
→ 修改其中一笔工作单产品
→ 回列表确认摘要刷新
→ 打开该笔抽屉确认寄出
```

预期：批量打印不登记寄出；修改工作单刷新批量页；确认仍只能在单笔抽屉内完成，确认后该笔从批量打印列表移除并出现在订单详情出货记录。

## 3. 回归检查

- 是否在批量打印页加入纳品书、保障确认书或套打入口？
- 是否建立打印批次台账，或把多笔准备合并成一笔寄送？
- 是否重新出现面单作废、录号、更正的旧环节？
- 是否重新出现打印编号清单？
- 是否把批量打印产品摘要改回名称+颜色聚合？
- 是否将返送寄送混入订单批量打印面单页？

## 4. Definition of Done

- 订单批量打印页只列订单来源准备中寄送，勾选、张数、汇总、批量生成、修改工作单后刷新均通过。
- 面单／纳品书／保障确认书／寄送通知邮件的正式模板样式与内容经客户确认并以正式 spec 转正；转正前不把样式与措辞视为已验收。
- 无新增的撤回、冲正、解锁、打印批次台账、套打入口或打印编号清单。
