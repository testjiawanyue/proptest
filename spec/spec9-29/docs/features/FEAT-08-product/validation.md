# FEAT-08 产品列表 Validation

> **本次修订验证状态（2026-09-25）**：以下修改及新增场景为验收要求，均未执行；历史 demo 核对、旧测试结果不表示本次规则已验证。原型资产未更新，冲突表现以本次正文为准。

本文件按 spec.md 的页面结构逐页验证，再验证「入库 → 组装 → 列表 → 详情 → 删除」完整闭环。用例依据 spec 与业务理解编写，覆盖 demo 已实现与未实现部分；demo 未实现项在对应用例注明。

## 1. 产品列表

### VAL-01 默认视图与生产阶段筛选

打开产品列表，初次进入默认显示已完成质检的产品；切换生产阶段为「在制」「待质检」；清除生产阶段筛选。

预期：初次进入只显示已完成质检产品；切换后列表收窄；清除筛选后显示全部。

### VAL-02 范围查询

### VAL-01b 重置行为

范围查询模式，输入起止编号并查询，切换生产阶段为「在制」，切换首次出货为「已首次出货」；点「重置」。

预期：起止编号、单件、部件输入清空，范围条件取消，首次出货恢复全部；生产阶段保持「在制」不变，编号前缀与查询模式保留。

### VAL-02a 范围查询

范围查询模式，前缀 PTG，输入 26001～26005，点「查询」。

预期：列表只显示该范围内产品；只填起始或结束时不生效；清空后恢复。

### VAL-03 单件查询

单件查询模式，输入完整製造番号（例：PTG26004），回车。

预期：命中直接进入该产品详情；输入不存在的编号提示「未找到该产品编号」，留在列表。

### VAL-04 部件反查

部件反查模式，输入当前已绑定的气囊编号（例：AQ-26004），回车。

预期：命中当前绑定该部件的产品直接进入详情；输入未绑定部件编号提示「未找到绑定该部件的产品」。

### VAL-05 列表列内容

任意一行产品。

预期：产品列只显示製造番号（无 M番号）；生产阶段标签颜色正确（在制灰／待质检橙／已完成质检绿）；对外名称未命名显示「未命名」；当前组成三行显示部件编号，未安装显示「-」；首次出货未出货显示「待首次出货」。

### VAL-06 产品状态标签

分别查看：有报废事实的产品、有当前订单关系的产品、无当前订单关系的产品。

预期：分别显示「已报废」（红）、「已关联订单」（蓝）、「未关联订单」（灰）。

### VAL-07 删除阻断——绑定部件

对有气囊绑定的产品执行「删除产品」。

预期：阻断弹窗列出「当前仍绑定部件，请先解除部件绑定」；数据无变化。

### VAL-08 删除阻断——多原因

对同时有部件绑定、质检记录、出货记录的产品执行「删除产品」。

预期：阻断弹窗一次性列出全部命中原因（绑定部件＋质检记录＋出货记录）。

### VAL-09 删除执行与历史保留（详见 VAL-09a）

### VAL-08b 删除阻断——受付记录

对有受付记录但无部件绑定、无质检、无出货的产品执行「删除产品」。

预期：阻断弹窗列出「已存在受付记录」；数据无变化。

### VAL-09a 删除执行与历史保留

对无任何阻断的产品执行删除并确认：仅当前衣体绑定，非衣体绑定均已结束，无质检、出货及受付记录；预置历史安装、拆除、组装和衣体资料更正记录。分别覆盖所属入库记录还有其他有效成员、删除后没有有效成员两种情况。

预期：确认弹窗说明产品及衣体退出当前有效范围、原历史保留、非衣体不随删、M番号不复用及制造编号可重新入库。确认后：

- 产品与衣体不在当前有效列表、选择和后续业务范围；
- 原产品及衣体身份、全部历史绑定、组装和衣体资料更正仍可读，能辨认原对象和事件；
- 非衣体部件档案及其在本产品、其他产品上的历史不受影响；
- 该衣体不计入原入库记录有效成员；还有有效成员时继续展示，没有有效成员时不作为有效记录展示，历史登记信息保留；
- 同制造编号可重新入库，但新产品与新衣体均为独立身份，不继承原历史；原 M番号不复用；
- 正常更换衣体并不产生另一个需要保留或删除的系统旧衣体对象。

### VAL-10 删除取消

对无阻断产品执行删除，在确认弹窗点「取消」。

预期：弹窗关闭，数据无变化。

### VAL-11 分页

列表超过 20 台时翻页。

预期：每页 20 条，底部显示总数。

## 2. 产品详情

### VAL-12 基本信息展示

打开一台已完成质检产品的详情。

预期：页头为製造番号（无 M番号）；基本信息八项齐全（製造番号、对外产品名称、衣体规格、首次质检通过日、首次出货、生命周期基准月、业务类型、资料存放路径）；不显示「建立时间」「操作人」。

### VAL-13 阶段提示条

分别打开一台在制产品（缺气囊）和一台待质检产品。

预期：在制产品显示提示条，列出缺少的部件名称；待质检产品显示提示条，引导前往质检工作台；已完成质检产品不显示提示条。

### VAL-14 生命周期

打开一台已出货产品（生命周期基准月 2026-09）的详情；再打开一台未出货产品。

预期：已出货产品生命周期表格 5 行——1年目 2027-09（基准月 + 1 年）、2年目 2028-09、3年目 2029-09、4年目 2030-09（定期点检）、5年目 2031-09（报废计划，基准月 + 5 年）；出货当年无年次。已有受付的年次显示「已计入 · 日期」；未出货产品显示空状态「首次出货后生成生命周期日程」。

### VAL-15 当前部件表格

打开一台部件齐全的产品。

预期：固定 5 行（衣体／气囊／传感器／发生器位置 1／发生器位置 2）；衣体操作只有「更换衣体」；传感器操作有「更换」「版本升级」「拆除」；发生器位置 2 未安装时显示「未安装」。

### VAL-16 更换衣体

点击衣体行「更换衣体」。

预期：确认弹窗说明线下实物更换、产品和系统衣体身份及绑定不变，无新编号输入框；取消不登记事件，确认则实际登记“更换衣体”，不引导去组装绑定。制造编号 PTG26001、产品及衣体身份与绑定均不变，不创建新衣体或线上报废对象，不触发产品报废，不自动更改衣体资料。

### VAL-17 更换部件

对气囊执行「更换」，输入新编号保存。

预期：弹窗默认带出旧部件当前资料；确认后旧绑定结束、新绑定建立；相关业务历史「部件与版本」页签出现更换事件（旧编号 → 新编号）。

### VAL-18 拆除部件

### VAL-17b 更换传感器（含固件版本）

对传感器执行「更换」，选择新部件资料、输入新编号、选择固件版本保存。

预期：旧绑定结束、新绑定建立；当前部件表显示新编号与新固件版本标签；「部件与版本」页签出现更换事件与固件版本记录。

### VAL-17c 资料不一致确认

更换部件时，新编号已在系统中建档且该编号当前资料与弹窗中选择的资料不一致。

预期：弹窗内显示确认区，说明该编号当前资料与所选资料；选择「以所选资料为准」→ 更换完成并追加资料更正记录（从旧资料更正为所选资料，不覆盖旧值）；选择「取消」→ 放弃更换。产品详情与组装工作台行为一致。

### VAL-18a 拆除部件

对发生器位置 2 执行「拆除」并确认。

预期：绑定结束，当前部件表该行显示「未安装」；部件追溯中该部件当前归属变为「未绑定」。

### VAL-19 版本升级

对传感器执行「版本升级」，选择新版本保存。

预期：追加版本记录；当前部件表固件版本标签更新；「部件与版本」页签出现升级事件（旧版本 → 新版本）；旧版本记录保留在历史中。

### VAL-20 补录部件（在制产品）

在制产品缺少气囊，点击气囊行「补录」，选择资料、输入编号保存。

预期：建立绑定；当前部件表显示新编号；阶段提示条更新（如已满足最低构成则变为待质检提示）。

### VAL-21 补录入口隐藏

### VAL-20b 质检后拆除不退阶段

已完成质检的产品，拆除一个必需部件（如气囊）。

预期：生产阶段仍为「已完成质检」；列表「已完成质检」筛选下仍可见。

### VAL-21a 补录入口隐藏

已完成质检产品的当前部件表。

预期：未安装槽位不显示「补录」按钮。

### VAL-22 资料存放路径

在基本信息「资料存放路径」输入框录入 NAS 路径，失焦。

预期：保存成功提示；刷新后值保留。

### VAL-23 相关业务历史——全部页签

打开有完整业务历史的产品，默认显示「全部」页签。

预期：默认选中「全部」；事件为其他 5 个页签的完整合集（含安装、初始版本、名称变更），按时间倒序；每条记录含事件名称与核心内容、操作人（无值显示 system；部件与版本页签统一显示 system）、发生时间；无表格、无展开行、无跳转按钮。

### VAL-24 相关业务历史——各页签内容

分别切换到 6 个页签。

预期：生产与资料含建立产品、名称变更、生产安装、初始版本、首次质检；出货与订单含正式出货（订单号／寄送编号／下单方 → 納品先）与订单关系结束（订单号／结束原因）；点检与维修每次受付一条——有年度显示「N年目定期点检」、无年度显示「定期点检」、非定期点检类型直接显示类型名不拼年度；部件与版本含安装／拆除／非衣体更换／版本事件（旧值 → 新值），衣体实物更换只显示“更换衣体”；返送与最终去向只含正式返送、确认回收、确认报废。

### VAL-25 衣体更换历史格式

查看一台更换过衣体的产品的「部件与版本」页签。

预期：事件内容仅显示“更换衣体”，无旧衣体编号、新衣体编号或编号对照；事件时间与操作人仍按 spec §5.4 展示。旧原型／demo 的通用换件格式不作为本次验收依据。

## 3. 页面间完整闭环

### VAL-26 入库 → 组装 → 质检 → 列表 → 详情闭环

1. 衣体入库新编号（见 FEAT-05 衣体入库 VAL-06）；
2. 部件组装完成三类必需部件（见 FEAT-06 部件组装 VAL-09）；
3. 质检工作台确认质检（见 FEAT-07 质检）；
4. 产品列表「已完成质检」筛选下找到该产品；
5. 进入详情查看基本信息、生命周期、相关业务历史。

预期：入库后产品即在列表（在制）；组装完成后变为待质检；质检后变为已完成质检；详情显示完整部件构成与历史事件。

### VAL-27 删除后衣体重入闭环

删除一台无阻断产品后，用同一衣体编号重新入库。

预期：入库不命中「已有档案」；新产品配发新 M番号（不复用旧值）；新产品的相关业务历史只包含本次新建产品的事件（建立产品等），不继承被删除产品的旧历史；原产品及衣体历史仍属于原身份并保持可读，不能按相同编号改指新对象。新衣体为新入库记录的成员，原已删除成员不恢复。

### VAL-08c 删除阻断保留出货记录原范围

对仍有准备中出货记录的产品请求删除；另覆盖正式出货记录。其余阻断条件按现有状态记录，不以是否打印文件缩小出货记录判定范围。

预期：两类出货记录均命中出货记录阻断；不将条件改为仅“正式寄出”，不新增其他阻断条件。

## 4. 回归检查清单

- 删除保留原产品与衣体历史，非衣体档案不随删；衣体实物更换只登记事件，四项身份／编号／绑定不变。

- 任何界面是否露出 M番号（列表、详情、历史、删除弹窗均不应显示具体 M番号值）？
- 删除产品后其 M番号是否被后续新建产品复用（不应复用）？
- 更换衣体是否改变了製造番号（不应改变）？
- 在制产品是否出现在「已完成质检」默认筛选中（不应出现）？
- 产品详情是否仍存在「当前业务归属」大卡（应已删除）？
- 相关业务历史是否出现表格、展开行或跳转按钮（应全部统一为时间线纯文本）？
- 删除有质检记录的产品是否被阻断（应阻断）？
- 部件反查是否命中已拆除部件的历史绑定（应只命中当前绑定）？

## 5. Definition of Done

- 产品列表覆盖全部生产阶段，三种查询方式可用，删除按规则阻断与执行；
- 产品详情基本信息、生命周期、当前部件、相关业务历史六页签完整；
- 更换衣体为确认制，不改变製造番号；
- 删除产品与衣体退出当前范围且原历史保留，非衣体档案不随删；M番号不复用，衣体编号重入建立独立身份；
- VAL-01 ～ VAL-27（含 VAL-01b／08b／08c／17b／17c／20b）全部通过；回归检查清单无命中。

- 本次关联验收门槛：修改和新增用例须取得实际验证证据后才可判定通过；不得沿用旧级联删除、新旧衣体编号对照、订单级保障确认书的预期。
