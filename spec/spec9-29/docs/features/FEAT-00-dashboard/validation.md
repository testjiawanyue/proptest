# FEAT-00 首页看板 Validation

依据 [spec.md](spec.md) 验收。本页为纯统计展示，用例聚焦各卡片口径的正确性与跳转；通过在其他模块构造数据后观察看板数字变化来验证。

## 1. 统计口径用例

### VAL-01 订单一览：租赁／销售／替代分列

操作：在订单管理中分别建立租赁、销售、替代订单，部分发货使其分别处于「未发完」「已发完」状态。

预期：订单一览的「租赁订单」「销售订单」「替代订单」三列分别统计本类型的进行中单数（= 未发完，含一台未发；已发完不计入进行中）；明细显示本类型剩余待发台数合计；已结束订单不计入。

### VAL-02 待办事项：今日要发货与逾期未发

操作：建立三笔仍有剩余待发的订单，预计发货日分别填今天、昨天、不填；其中一笔发完。

预期：「今日要发货」只计入预计发货日为今天且仍有剩余待发的订单，附剩余待发台数；「逾期未发」只计入预计发货日早于今天且仍有剩余待发的订单，单数大于 0 时数字为红色；已发完的订单即使预计发货日已过也不计入；未填预计发货日的订单两项都不计入。

### VAL-03 厂内作业：待清洗／待返送／今日受付

操作：(a) 受付一台要求清洗的产品，登记清洗完成前后各看一次；(b) 受付一批处置决定为返回客户的产品，实际返送前后各看一次；(c) 今天新建若干受付。

预期：(a) 待清洗在登记清洗完成后减 1；产品回收或报废后不再计入。(b) 待返送按大番号计数，批内产品全部实际返送（确认寄出）后该批不再计入；只认实际寄出——返送面单已建立或已打印但未确认寄出的产品，仍计入应返未返；处置决定不是返回客户、或已回收／已报废的产品不使批次计入。(c) 今日受付等于今天新建的有效受付台数，删除的受付不计入。

### VAL-04 今日作业：按工作组、按首次登记

操作：今天在縫製组登记一台作业、再多次修改同一台；在センサ组登记两台；另取一台昨天已首次登记、今天又修改的作业记录。

预期：縫製显示 1、センサ显示 2、其余组显示 0；同一台同组当天重复修改不重复计数；昨天首次登记、今天修改的记录不计入今日（只认首次登记时间）；次日再打开时今天的记录不再计入；作废的作业记录不计入。

### VAL-05 厂内库存：在制品／成品在库

操作：(a) 新建未过质检的产品；(b) 质检通过且当前无订单关系的产品；(c) 质检通过且有未结束订单关系的产品；(d) 受付侧确认回收一台已发货产品；(e) 从订单管理解除一台已发货产品的当前订单关系。

预期：(a) 计入在制品；(b) 计入成品在库；(c) 两者都不计入；(d)(e) 订单关系从任一入口结束后该产品都进入成品在库（不要求重新入库质检）；报废产品不计入成品在库。

### VAL-06 半成品：在制品／待质检／零件数

操作：构造两台在制品与一台已过质检产品——A（在制品）缺发生器、B（在制品）部件齐全未质检、C 已过质检；A 绑定气囊＋传感器，B 绑定气囊＋传感器＋发生器位置 1／2；另取一个气囊先绑定 A 再解除绑定。

预期：在制品 = 2（A、B）；待质检 = 1（B）；零件数只统计在制品当前有效绑定——气囊 2、传感器 2、发生器 2（B 的位置 1／2 各算一个）；已解除绑定的气囊不计入；衣体不计入；C 的绑定不计入。

## 2. 页面交互用例

### VAL-07 跳转链接

操作：依次点击六张卡片的跳转链接与厂内作业卡底部两个入口。

预期：订单一览／待办事项 → 订单管理；厂内作业「查看作业管理」→ 作业管理，底部「进入受付工作台」→ 受付工作台、「查看返送」→ 返送；厂内库存 → 产品管理；今日作业「查看作业管理」→ 作业管理；半成品 → 产品管理在制品视图。

## 3. 回归检查清单

- 看板数字不随任何「保存看板」类操作变化——本页无此操作，数字只随业务模块记录变化。
- 已删除／已作废的记录不出现在任何卡片口径中。
- 「今日」「逾期」跨日时区边界按日本业务日判断。
- 订单一览三列（租赁／销售／替代）均按同一口径统计；进行中 = 未发完（已发完不计入），无「需核对」。
- 待返送无「不再关注」类人工标记入口。
- 今日作业只有工作组维度，无人员维度。

## 4. Definition of Done

- §3 全部口径用例通过；§2 跳转用例通过。
- 在其他模块登记业务后，首页下次展示即反映，无需任何同步操作。
- 回归检查清单全部通过。
