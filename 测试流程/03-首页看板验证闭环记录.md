### 2.1 后端口径核对（`dashboard/service/PropDashboardService.java` + `PropDashboardMapper.xml`）

后端 `read()` 用 `Clock.systemUTC().withZone(Asia/Tokyo)` 取**日本业务日**；聚合 4 个 SQL：`selectOrders` / `selectFactory` / `selectProducts` / `selectTodayWork`。

| 口径（spec §3） | 实现核对 | 结论 |
|---|---|---|
| 订单一览·进行中=未发完(含一台) | `selectOrders` 取 `order_status='active'`，`WHERE remaining>0`（remaining=订购−有效发货），已发完/已结束自然不进 | ✅ 符合 VAL-01 |
| 订单一览·剩余待发 | `SUM(remaining)` 按类型合计 | ✅ |
| 待办·今日/逾期只计 remaining>0 | `dueBucket` 仅 today/overdue 进 todos；`other`(含未填)→default null→不计数 | ✅ 符合 VAL-02 |
| 待办·逾期>0 红色 | 前端 `metric.overdue && count>0` 着色 | ✅（前端） |
| 厂内作业·待清洗/待返送/今日受付 | `selectFactory`：三者均 `p.deleted_time IS NULL AND p.scrapped_time IS NULL`（待清洗/待返送）；今日受付仅 `p.deleted_time IS NULL` | ⚠️ 见 C-2 |
| 厂内库存/半成品·报废排除 | `selectProducts` `WHERE p.deleted_time IS NULL AND p.scrapped_time IS NULL` | ✅ **报废排除已实现**（spec §7 曾记"2026-10-23 尚未编码"，当前已补） |
| 半成品·待质检=部件齐全未质检 | `inspected=0 AND body=1 AND airbags=1 AND sensors=1 AND inflator1=1` | ✅ 符合 VAL-06 |
| 半成品·零件数=在制品当前有效绑定 | `LEFT JOIN ... ended_time IS NULL`，衣体(slot_type=body)不计入，inflator_1+inflator_2 各计 | ✅ 符合 VAL-06 |
| 今日作业·五组首次登记 | `selectTodayWork` 按 `g.create_time` 今日，`COUNT(DISTINCT product_id)` 防同组重复；`GROUP BY group_code` | ✅ 基本符合 VAL-04 |
| 统计仅认有效记录/日本业务日 | 各 SQL 排 `deleted`；业务日在 `read()` 取 Tokyo 日 | ✅ |

### 2.3 查证补充（C-1 / C-2 的落库机制，2026-11-13 查证）

为裁定 C-1/C-2，回到代码确认"作废/报废"如何表示：

- **代码无独立"作废(void)"状态**：全 `prop_new/src` 检索中文"作废"零命中；订单有 `cancelOrder→status='cancelled'`（那是"取消"，非"作废"）。
- **产品侧软删除列**：`prop_product` 有 `deleted_time`(删除) 与 `scrapped_time`(报废)；看板 `selectProducts`/`selectFactory` 均 `WHERE p.deleted_time IS NULL AND p.scrapped_time IS NULL`。
- **"作废/不合格"标记**：批处理 `WorkMapper` 用 `invalid_count`/`invalid` 派生（首检有效且未处置/未填电缆外观作业 → invalid=1）。这是受付/产品"作废(不合格)"在代码里的落点。
- **今日作业 / 今日受付的 SQL**：`selectTodayWork`、`receivedToday` **只过滤 `p.deleted_time IS NULL`**，既未排 `scrapped_time`(报废)、也未排 `invalid`(作废/不合格)。
- **结论（查证后）**：按 spec §5「已删除、已报废、已作废一律不参与统计」，今日作业/今日受付对报废与作废产品的排除，**与同看板其他卡片不一致 → C-1/C-2 倾向真实缺陷**（需补 `AND p.scrapped_time IS NULL` 及 invalid 排除）。待你最终裁定。
