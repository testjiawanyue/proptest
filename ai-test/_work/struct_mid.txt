产品生产/部件组装-021 优先级:中
【用例标题】录入编号部件类型与列不符报错
【测试点】验证在某一部件列输入其他类型部件编号时被拦截。
【前置条件】系统中已存在如下数据：已选择各类默认资料；存在已建档的传感器编号 SN-26001。
【测试步骤】1. 在气囊编号列输入 SN-26001 并保存
【预期结果】1. 行内红色错误说明部件类型与所在列不符
2. 不建立绑定
【备注】补充来源：spec §4.6 及 VAL-16。

产品生产/部件组装-025 优先级:中
【用例标题】默认资料切换不回改已保存行
【测试点】验证切换顶部默认资料只影响之后新录入，已保存行保持原资料。
【前置条件】系统中已存在如下数据：一行已按气囊 A型保存；存在气囊 B型资料。
【测试步骤】1. 将顶部默认气囊资料切换为 B型
2. 在新行录入另一个气囊新编号并保存
3. 查看原已保存行
【预期结果】1. 已保存行资料保持 A型不变
2. 新录入编号按 B型建档绑定
【备注】补充来源：spec §4.5"顶部默认资料切换"及 VAL-15；有未保存输入时切换应先二次确认（提示将按新默认资料保存）。

产品生产/质检工作台-016 优先级:中
【用例标题】筛选后勾选状态在切换筛选时保留
【测试点】验证重新筛选后不在当前清单的已勾选产品不参与本次确认。
【前置条件】系统中已存在如下数据：范围筛选可显示至少 3 台待质检产品。
【测试步骤】1. 范围筛选显示 3 台，勾选其中 2 台
2. 改用番号入力定位另一台产品
3. 点击确认质检通过
【预期结果】1. 番号入力后清单只显示定位的 1 台
2. 原先勾选但不在当前清单的 2 台保留勾选、不参与本次确认；按钮仅统计当前清单选中数
【备注】补充来源：spec §4.5 及 VAL-11。

产品管理/产品列表查询-006 优先级:高
【用例标题】生产阶段筛选仅显示对应阶段产品
【测试点】验证生产阶段下拉选择后仅显示该阶段产品。
【前置条件】系统中已存在如下数据：存在在制、待质检、已完成质检三种阶段产品。
【测试步骤】1. 生产阶段下拉选择"已完成质检"
【预期结果】1. 下拉选择即时生效，无需点击查询
2. 列表仅显示已完成质检阶段产品，在制与待质检产品不显示
【备注】【已修正】依据 spec §4.5 及 VAL-01，阶段下拉即时生效、初次默认已完成质检、清除后显示全部；阶段由部件构成与质检事实派生。

产品管理/产品删除-002 优先级:高
【用例标题】当前仍绑定气囊／传感器／发生器部件（需先解除绑定）
【测试点】验证存在有效绑定部件关系时产品不能删除。
【前置条件】系统中已存在如下数据：PTG26001 存在有效 绑定部件。
【测试步骤】1. 对 PTG26001 点击删除产品并确认
【预期结果】1. 检出阻断原因，提示已关联部件不可删除，产品数据保留
2. 解除部件绑定关系后可以删除产品
【备注】【已修正】依据 spec §4.6，删除阻断条件仅四项：绑定部件、质检记录、出货记录、受付记录；"当前订单关系"不在阻断条件中，本用例"已关联订单不可删除"不成立（订单关系解除由订单模块处理）。
