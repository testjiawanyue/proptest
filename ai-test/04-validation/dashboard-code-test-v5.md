## 12. 高风险冲突与未确认行为

1. **【冲突】今日作业-004**：当前代码统计所有当日 `prop_work_group` 行，没有作废/无效过滤；V5 预期排除 1 条作废记录，无法满足。需先确认“作废”的数据表示，再让首页复用 `WorkMapper.receiptSummary` 的 `invalid` 判定或新增明确的作废标记/过滤条件。
2. **【部分支撑】订单一览-009**：当前订单只有 cancelled 状态，没有删除接口/删除字段；“删除订单”无法作为独立路径验证。若上游存在物理删除历史行，统计自然排除；否则用例应改为“取消订单”。
3. **【部分支撑】厂内作业-011**：看板与产品筛选已统一排除报废产品，但报废时解除非衣体绑定、保留部件个体与历史绑定属于上游作业流程；本模块只读，未运行验证前置动作。
4. **【边界待裁决】** 今日受付、今日作业只排除产品 `deleted_time`，未排除 `scrapped_time`（BR-052/053）；若“有效记录”要求报废产品也不计入，需要补过滤与用例。
5. **【静态限制】** 东京时区、MySQL 会话时区、骨架布局、真实通知次数未运行验证；本文件只判断代码行为是否有支撑。

## 13. 建议补充或调整测试用例
